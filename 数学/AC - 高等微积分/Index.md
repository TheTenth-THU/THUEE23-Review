## 课程知识主线

高等微积分研究「有限变化如何通过极限进入连续模型，以及局部信息如何控制整体性质」。课程从实数完备性和极限出发，经由微分建立局部线性化，再由积分完成从局部量到总体量的累积；级数把有限运算推广到无限过程，多元分析则把同一套思想推广到高维空间与向量场。

核心依赖链为：**实数完备性** $\rightarrow$ **极限与连续** $\rightarrow$ **微分与局部近似** $\rightarrow$ **积分与整体累积**。在此基础上，一条分支通向微分方程，另一条分支通向一致收敛和函数展开；二者与多元微积分共同构成综合应用层。

## 知识点导航

### 分析基础

[[分析基础]]解释分析学为何需要实数完备性，并组织以下两章：

+ [[实数完备性与数列极限]]：以确界原理、单调有界定理、区间套、列紧性和Cauchy准则为存在性工具，建立数列极限的判定与计算。
+ [[一元函数的极限与连续]]：从函数极限过渡到连续性、一致连续性以及闭区间上连续函数的整体性质。

### 一元微分学

[[一元微分学]]围绕「局部线性近似如何推出整体性态」展开：

+ [[导数与微分]]：定义导数和微分，统一复合、反函数、隐函数与参数方程的求导规则。
+ [[中值定理与函数性态]]：以Rolle、Lagrange和Cauchy中值定理连接局部导数与区间整体性质，并研究单调性、极值、凹凸性和渐近线。
+ [[Taylor公式与近似]]：用有限阶多项式及余项描述局部近似，服务于极限、估计和高阶性质分析。

### 一元积分学

[[一元积分学]]区分「寻找原函数」与「Riemann和的极限」两种问题，再由微积分基本定理连接二者：

+ [[不定积分]]：整理换元、分部积分和可有理化等原函数计算方法。
+ [[Riemann积分与可积性]]：从带点分割定义积分，比较Darboux和、振幅与零测度判据。
+ [[微积分基本定理与定积分计算]]：连接导数与积分，并组织换元、分部、对称性和典型积分计算。
+ [[定积分的应用]]：把积分用于面积、弧长、体积、旋转曲面面积和质心。
+ [[广义积分]]：将积分区间或被积函数的奇性纳入极限框架，并讨论收敛性。

### 常微分方程

[[常微分方程]]把导数关系视为未知函数的约束：

+ [[一阶常微分方程]]：识别可分离、齐次、一阶线性和Bernoulli等可化归类型。
+ [[可降阶的高阶常微分方程]]：利用方程中缺失的自变量或未知函数实施降阶。
+ [[高阶线性常微分方程]]：讨论线性解空间、常系数高阶方程和Euler方程。
+ [[线性常微分方程组]]：用矩阵指数与特征结构统一线性方程组的求解。

### 无穷级数

[[无穷级数]]围绕「有限运算何时可以安全推广到无穷过程」展开：

+ [[常数项级数]]：从部分和出发，比较正项、交错项与一般数项级数的判敛工具。
+ [[函数列与函数项级数]]：区分逐点收敛和一致收敛，并说明极限与连续、积分、求导交换的条件。
+ [[幂级数]]：以收敛半径组织逐项运算和Taylor展开。
+ [[Fourier级数]]：把函数视为三角函数系中的展开，比较逐点收敛与平方平均收敛。

### 多元分析基础

[[多元分析基础]]把一元极限和微分推广到欧氏空间：

+ [[欧氏空间与多元连续性]]：建立开闭集、紧致性、连通性、多元极限和连续性。
+ [[多元函数的微分]]：以线性映射定义全微分，辨析偏导、方向导数、梯度和Jacobi矩阵。
+ [[隐函数与反函数]]：用Jacobi矩阵的非退化性刻画局部可解性和局部可逆性。
+ [[多元Taylor公式]]：以梯度和Hessian矩阵建立一阶、二阶局部近似。
+ [[多元函数的极值]]：由二阶近似研究无约束极值，并用Lagrange乘数法处理约束极值。
+ [[空间曲线与曲面]]：用参数化、切空间和法向量描述局部几何。

### 多元积分与向量分析

[[多元积分与向量分析]]把累积过程推广到区域、曲线和曲面，并用积分定理连接边界与内部：

+ [[重积分]]：处理Jordan可测区域、累次积分、坐标变换及几何物理应用。
+ [[曲线积分与Green公式]]：区分第一类与第二类曲线积分，并由Green公式连接边界环流与区域内部。
+ [[曲面积分与Gauss-Stokes公式]]：处理定向曲面上的通量，并由Gauss、Stokes公式连接曲面、边界和微分算子。
+ [[保守场与势函数]]：比较路径无关、有势、保守和无旋的等价条件及其适用域。

### 含参积分

[[含参积分]]综合[[函数列与函数项级数|一致收敛]]与积分理论，判断极限、求导、积分和参数积分次序何时能够交换，并整理Gamma函数与Beta函数。
