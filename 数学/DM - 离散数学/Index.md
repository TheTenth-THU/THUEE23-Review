## 知识地图

离散数学研究有限或可数结构及其推理规则。本课程由四条相互衔接的主线组成：

+ [[数理逻辑]]建立形式语言、真值语义与有效推理。
    + [[命题逻辑]]以完整命题为原子，讨论联结词、范式和推理。
    + [[谓词逻辑]]进一步分析个体、谓词、量词和辖域。
+ [[集合论]]提供描述离散对象、关系和映射的统一语言。
    + [[集合与集合运算]]讨论集合、幂集、笛卡儿积和集合恒等式。
    + [[二元关系]]讨论关系性质、闭包、等价关系和偏序关系。
    + [[函数]]讨论单射、满射、复合与逆函数。
+ [[代数结构]]研究集合上运算所满足的公理以及结构保持映射。
    + [[代数系统与同态]]建立运算、同态和同构的一般框架。
    + [[群]]讨论可逆运算、子群、循环群、陪集和 Lagrange 定理。
    + [[环与域]]组织加法与乘法两种运算。
    + [[格与布尔代数]]把偏序中的上确界、下确界与逻辑运算连接起来。
+ [[图论]]以顶点和边描述对象间的连接关系。
    + [[图的基本概念与连通性]]建立度、路、圈、连通与割的语言。
    + [[树与生成树]]研究最小连通结构及加权生成树。
    + [[Euler图与Hamilton图]]分别研究遍历全部边和全部顶点的问题。
    + [[二部图]]研究可分为两个独立顶点集的图。
    + [[平面图与图着色]]研究平面嵌入、Euler 公式和相邻冲突分配。

辅助口试题见 [[QUESTIONS]]，题库不纳入 Longform scenes。
