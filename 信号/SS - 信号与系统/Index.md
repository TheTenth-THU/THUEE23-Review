## 课程知识地图

信号与系统研究「信号如何表示、系统如何作用以及输入如何决定输出」。知识链从连续与离散时间信号的时域描述出发，经由卷积和常系数方程建立 LTI 系统分析，再用 Fourier、Laplace 与 $z$ 变换把运算转化为频谱或极点问题，最终进入状态空间、滤波、抽样和相关分析。

## 知识点导航

+ **[[系统]]**：建立系统模型、方框图与信号流图，定义线性、时不变、因果、稳定和可逆等基本性质。
+ **[[连续时间系统时域分析]]**：从典型连续信号及其分解出发，用微分方程、冲激响应和卷积求解连续时间 LTI 系统。
+ **[[离散时间系统时域分析]]**：研究序列运算、典型序列、差分方程、单位样值响应与离散卷积。
+ **[[变换]]**：统一组织时域与变换域之间的表示工具。
    + **[[Fourier 级数 (FS)]]**与 **[[Fourier 变换 (FT)]]**：建立周期与非周期连续信号的频谱表示及其性质。
    + **[[Laplace 变换 (LT)]]**：通过收敛域和复频域统一暂态、稳态及系统极点分析。
    + **[[z 变换]]**与 **[[离散时间 Fourier 变换 (DTFT)]]**：建立离散时间序列的复频域与单位圆频域表示。
    + **[[离散余弦变换 (DCT)]]**：通过偶对称延拓获得实数余弦基表示，服务于能量压缩与图像编码。
+ **[[连续时间系统频域分析]]**与 **[[离散时间系统频域分析]]**：利用系统函数、零极点和频率响应分析系统的因果性、稳定性与选频行为。
+ **[[系统的状态变量分析]]**：把高阶方程改写为一阶状态方程，研究状态转移、可控性、可观性与稳定性。
+ **[[信号]]**：连接变换工具与信号处理任务。
    + **[[连续时间信号处理的 Fourier 分析]]**：研究无失真传输、滤波、调制、抽样与恢复。
    + **[[信号的相关性分析]]**：从信号空间、正交展开和相关函数进入能量、功率与匹配比较。
