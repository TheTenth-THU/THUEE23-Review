## 知识主线

数字信号处理研究如何把连续世界中的信号转化为离散序列，并在变换域或系统结构中完成分析、滤波与估计。全课程可以沿六条相互衔接的主线展开：

+ **离散化**：[[采样与量化]]说明连续信号如何经采样和量化成为数字信号，[[多采样率处理]]进一步研究采样率转换及其高效结构。
+ **表示与变换**：[[变换与表示]]从序列和LTI系统出发，依次引向[[离散时间 Fourier 变换 (DTFT)|DTFT]]、[[离散 Fourier 变换 (DFT)|DFT]]、[[数字频谱分析]]与[[离散余弦变换 (DCT)|DCT]]。
+ **系统与滤波**：[[滤波与系统]]以频率指标为入口，通过[[𝑧 变换]]连接系统函数、极零点与稳定性，再分别讨论[[IIR 滤波器]]、[[FIR 滤波器]]和[[Hilbert 变换]]。
+ **数值实现**：[[有限字长效应]]说明表示量化、系数量化、运算噪声和溢出如何使理论系统偏离实际实现。
+ **数据驱动调整**：[[自适应滤波]]在系统未知或时变时，根据输入、期望响应和误差在线更新滤波器系数。

> [!note] 从理论到实现
> DTFT和 $z$ 变换刻画无限长序列与系统，DFT和FFT提供有限数据上的可计算形式；滤波器结构把系统函数落实为运算网络，有限字长分析检验其数值可靠性，自适应算法则让结构能够随数据变化。

## 章节导航

### 采样、量化与采样率转换

+ [[采样与量化]]：理想冲激采样、Nyquist条件、带通采样与标量量化模型。
+ [[多采样率处理]]：抽取、零插、有理数倍变换、多相结构和均匀DFT滤波器组。

### 离散信号的表示与频域计算

+ [[变换与表示]]：离散时间信号、LTI系统及其差分方程和卷积表示。
+ [[离散时间 Fourier 变换 (DTFT)]]：定义、逆变换、典型变换对与基本性质。
+ [[离散 Fourier 变换 (DFT)]]：周期运算、FFT、快速卷积、短时分析与OFDM。
+ [[数字频谱分析]]：由有限采样估计连续频谱时的混叠、泄漏、栅栏效应与分辨率。
+ [[离散余弦变换 (DCT)]]：偶对称延拓、快速计算及能量集中特性。

### 系统分析与滤波器设计

+ [[滤波与系统]]：频带指标及从系统描述到实现结构的设计路线。
+ [[𝑧 变换]]：收敛域、逆变换、极零点、稳定性、全通与最小相位系统。
+ [[IIR 滤波器]]：直接、级联、并联实现，以及模拟原型到数字滤波器的映射。
+ [[FIR 滤波器]]：直接与频率取样结构、线性相位条件和窗函数设计。
+ [[Hilbert 变换]]：连续与离散Hilbert变换、解析信号和单边频谱。

### 实际运算与在线学习

+ [[有限字长效应]]：量化噪声传播、系数灵敏度、溢出与压缩比例因子。
+ [[自适应滤波]]：Wiener最优解、最速下降、LMS、RLS及干扰对消等应用。
