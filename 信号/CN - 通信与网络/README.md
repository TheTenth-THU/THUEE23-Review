## 知识主线

通信系统围绕「信息如何表示、如何传输、如何可靠共享」展开。复习时先用信息论建立信源与信道的极限，再沿数字化、调制、差错控制进入物理层实现，最后讨论多用户接入、交换与路由。

## 重点结构

+ [[信息论]]给出通信系统的统一抽象。
    + [[信源]]研究熵、互信息与无失真／有失真信源编码。
    + [[信道]]研究离散信道、信道容量与 Shannon 极限。
    + [[加性白 Gauss 噪声 (AWGN)]]建立连续时间噪声信道模型。
+ [[模拟信源的数字编码]]连接采样、量化、压缩编码与数字比特流。
+ [[数字调制]]把比特映射到可传输的物理信号。
    + [[电平信道]]讨论最优判决及误符号率、误比特率。
    + [[波形信道]]讨论成形脉冲、匹配滤波与最佳接收。
    + [[载波传输]]讨论 Nyquist 准则、升余弦成形、基带与带通传输。
+ [[差错控制]]通过检错、纠错、重传与交织提高可靠性。
+ [[多用户通信]]讨论多址与复接、随机接入、交换和广域路由。

## 复习指引

先从 [[QUESTIONS|推免面试回忆题]] 闭卷诊断，再把问题放回「信源—编码—调制—信道—接收判决—网络共享」链路定位。沿对应正文补齐模型、带宽、功率、误码率、容量或协议状态后复答，并主动说明提高性能时付出的带宽、功率、复杂度或时延代价。
