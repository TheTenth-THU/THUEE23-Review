## 知识主线

本课程把微观规律与宏观统计规律连接起来。量子力学主线回答「量子态如何表示、演化和测量」，统计物理主线回答「大量微观状态如何产生稳定的热力学规律」。

## 重点结构

```mermaid
flowchart LR
    A[量子态] --> B[Schrödinger 演化]
    B --> C[力学量与测量]
    C --> D[表象与近似方法]
    D --> E[单粒子与全同粒子体系]
    E --> F[微观态计数]
    F --> G[平衡分布]
    G --> H[热力学量与典型体系]
```

### 量子力学

+ [[量子力学]]：量子态、演化、测量、表象与近似方法的总览。
+ [[波函数]]、[[Schrödinger 方程]]与[[力学量算符]]构成量子力学的基本语言。
+ [[一维束缚态与散射]]、[[一维线性谐振子]]和[[氢原子]]给出典型可解模型。
+ [[矩阵表象]]、[[Dirac 符号]]与[[绘景]]给出等价但各有侧重的描述方式。
+ [[电子自旋]]、[[外磁场中的原子]]和[[电磁场中的带电粒子]]体现内禀自由度与外场耦合。
+ [[微扰理论]]和[[量子跃迁]]处理不可精确求解或显含时间的相互作用。
+ [[全同粒子体系]]把单粒子量子力学过渡到量子统计。

### 热力学与统计物理

+ [[热力学与统计物理]]：从热力学状态量到统计分布的总览。
+ [[热力学的基本概念]]给出宏观约束，[[统计力学基本原理]]建立微观态与概率的桥梁。
+ [[近独立粒子系统]]统一推导 Bose、Fermi 与半经典极限下的平衡分布。
+ [[Boltzmann 统计理论]]以配分函数计算宏观量，[[理想气体]]是核心应用。
+ [[Bose 气体与凝聚]]、[[Fermi 气体]]讨论量子简并，[[光子气体与声子气体]]处理粒子数不守恒的玻色准粒子。
+ [[系综理论]]从微正则、正则和巨正则系综统一理解平衡统计。

## 复习指引

先做 [[QUESTIONS|推免面试回忆题]]，区分问题是在量子态、演化、测量与近似，还是在微观态计数、系综和统计分布上。复答量子题时写清 Hilbert 空间、算符、边界条件和可观测量；复答统计题时说明系综、守恒约束、粒子可分辨性与经典／量子极限，并把结果连接到宏观量。
