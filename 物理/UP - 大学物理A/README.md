## 知识主线

大学物理A以力学、电磁学、热学、振动与波、光学和近代物理建立基础物理图景。在当前仓库中，本课程暂时只有可与电磁场与波共同回答的面试回忆题，集中于电磁感应、Lorentz 力、全反射、光纤传播和 Rayleigh 散射；其他模块尚未形成正式课程笔记。

## 重点结构

+ [[QUESTIONS|推免面试回忆题]] 是当前唯一 scene，记录大学物理能够完整回答、同时属于电磁场与波的问题。
+ 电磁感应和带电粒子运动复用[[物理/EM - 电磁场与波/Maxwell's Equations|Maxwell 方程]]及[[物理/EM - 电磁场与波/Electric Fields|电场]]等正式笔记。
+ 几何光学、光纤和散射问题复用[[物理/EM - 电磁场与波/Electromagnetic Waves in Media|介质中的电磁波]]与[[物理/EM - 电磁场与波/Electromagnetic Waves at Boundaries|边界上的电磁波]]。
+ 力学、热学、振动与近代物理目前没有正式章节，不能用相邻课程链接冒充覆盖。

## 复习指引

先闭卷回答 [[QUESTIONS|推免面试回忆题]]，再沿关联链接回到电磁场与波笔记补齐定律、方向、单位、边界条件和极限情形。当前不按完整大学物理课程扩张复习范围；若以后补入正式章节，应先建立全课程知识地图，再把对应 scene 接在 `QUESTIONS` 之后。
