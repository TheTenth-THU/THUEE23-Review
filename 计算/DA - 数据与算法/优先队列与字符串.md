## 优先队列

**优先队列 (priority queue)** 保存带优先级的元素，支持插入和删除最小／最大元素。它不承诺按普通下标访问全部元素。

二叉堆是完全二叉树，可紧凑存于数组。以 0 为起始下标时，节点 $i$ 的子节点为 $2i+1$、$2i+2$，父节点为 $\lfloor(i-1)/2\rfloor$。

最小堆满足每个节点的键不大于其子节点：

+ 插入时把新元素放在数组末尾，再向上调整，时间 $O(\log n)$。
+ 删除最小值时用末元素替换根，再向下调整，时间 $O(\log n)$。
+ 查看最小值为 $O(1)$。
+ 自底向上建堆的总时间为 $O(n)$，不是 $O(n\log n)$。

优先队列用于 Dijkstra、Prim、事件模拟、任务调度和 Top-K。

## 字符串

**字符串 (string)** 是字符序列。实现需明确字符编码、长度单位、终止符和不可变性。朴素模式匹配在每个可能起点逐字符比较，最坏时间为 $O(nm)$。

## KMP 匹配

KMP 的核心是在失配时利用模式串自身的前后缀信息，避免主串指针回退。

定义前缀函数 $\pi[q]$ 为模式串前 $q+1$ 个字符中，既是前缀又是后缀的最长真子串长度。扫描主串时维护当前已匹配长度 $q$：

```text
for each character c in text:
    while q > 0 and pattern[q] != c:
        q = pi[q - 1]
    if pattern[q] == c:
        q = q + 1
    if q == pattern.length:
        report a match
        q = pi[q - 1]
```

预处理模式串耗时 $O(m)$，扫描主串耗时 $O(n)$，总时间 $O(n+m)$。

> [!danger] 前缀函数不包含完整字符串本身
> 「真前缀」长度必须小于当前子串长度。失配跳转到 $\pi[q-1]$，是把已匹配前缀替换为其最长可复用边界，而不是简单减一。

## 字符串与优先队列的共同方法

两类结构都通过维护局部不变量换取高效操作：堆只维持父子有序，不维持全局排序；KMP 只维护当前可复用边界，不保存全部匹配历史。

> [!tip]
> 判断结构是否合适时，关注所需操作而非名称。若需要频繁删除任意元素，普通堆并不直接支持；若需要多模式匹配，应考虑 Trie 或自动机，而非重复运行 KMP。
