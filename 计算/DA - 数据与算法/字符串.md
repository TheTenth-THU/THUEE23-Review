## 字符串的数据模型

**字符串 (string)** 是字符序列。它在逻辑上是线性结构，但字符编码会使「第 $i$ 个字符」与「第 $i$ 个字节」产生区别。

## 表示边界

实现必须明确字符编码、码点与字节的区别、长度单位、是否使用终止符以及对象是否可变。按字节随机访问在 UTF-8 中不等价于按字符随机访问；切片和拼接的复杂度也取决于是否复制底层存储。

字符串的数据表示与 [[#字符串匹配|模式匹配]] 共同构成一个复习闭环：前者决定长度和访问语义，后者利用序列结构设计高效查找。

## 字符串匹配

给定主串和模式串，目标是报告模式串在主串中的全部出现位置。朴素算法在每个可能起点重新比较，最坏时间为 $O(nm)$。

### KMP 匹配

KMP 的核心是在失配时利用模式串自身的前后缀信息，避免主串指针回退。

定义前缀函数 $\pi[q]$ 为模式串前 $q+1$ 个字符中，既是前缀又是后缀的最长真子串长度。扫描主串时维护当前已匹配长度 $q$：

```text
for each character c in text:
    while q > 0 and pattern[q] != c:
        q = pi[q - 1]
    if pattern[q] == c:
        q = q + 1
    if q == pattern.length:
        report a match
        q = pi[q - 1]
```

预处理模式串耗时 $O(m)$，扫描主串耗时 $O(n)$，总时间 $O(n+m)$。

> [!danger] 前缀函数不包含完整字符串本身
> 「真前缀」长度必须小于当前子串长度。失配跳转到 $\pi[q-1]$，是把已匹配前缀替换为其最长可复用边界，而不是简单减一。

> [!tip]
> 若需要多模式匹配，应考虑 Trie 或自动机，而非重复运行 KMP。
