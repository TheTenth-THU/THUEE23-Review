## 知识主线

本课程分为两条并列主干，而不是按课件出现次序串成一条线：

```text
数据与算法
├─ 数据结构：逻辑关系 → ADT 操作合同 → 存储表示 → 典型操作与算法
└─ 算法：问题规格 → 正确性与复杂度 → 通用设计 → 独立问题族
```

[[数据结构]]回答「数据如何组织以及哪些操作应当高效」；[[算法]]回答「如何从允许的输入得到正确输出，以及需要多少资源」。与某一数据结构直接绑定的实现、操作和典型算法保留在同一文件内；只有跨多种数据对象的通用设计方法和独立问题族才进入算法分支。

## 重点结构

### [[数据结构]]

通用的抽象数据类型、逻辑结构、存储表示和接口边界统一放在父章节。[[队列]]同时比较 FIFO、双端队列和优先队列；[[树]]同时说明二叉树、搜索树、堆、Huffman树和并查集；[[栈]]连接递归调用栈，[[字符串]]连接模式匹配，[[图]]连接遍历、最小生成树和最短路径。

### [[算法]]

父章节统一说明问题规格、正确性、复杂度和均摊分析。[[算法设计]]在同一文件内比较分治、动态规划、贪心、回溯、分支定界与随机化；[[查找]]、[[排序]]和[[数值算法]]是可独立复习的问题族。

[[数值算法]]统一保存浮点误差、条件性与稳定性等共享前提，其子章节再按问题分为[[线性方程组]]、[[数据拟合]]、[[数值插值]]、[[非线性方程]]和[[最优化]]。

> [!tip]
> 优先保持阅读局部性：理解一个对象时，应在同一文件中看到它的定义、表示、典型操作、直接算法和关键权衡。只有内容需要被多个对象共同复用，或者本身形成独立问题族时，才提升或拆成单独文件。

## 复习指引

先用 [[QUESTIONS|推免面试回忆题]] 定位知识断点。数据结构题不能只背实现代码，应连同接口语义、表示权衡和直接算法一起说明；算法题不能只背复杂度，应说明不变量和选择依据；数值题还要区分问题条件数、离散化误差、舍入误差与算法稳定性。
