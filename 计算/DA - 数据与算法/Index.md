## 课程知识地图

本课程把离散数据处理与连续数值计算放在同一框架下：先把问题抽象为数据、操作和目标，再选择表示、算法与误差控制方式。

```text
问题规格 → 数据表示 → 基本操作 → 算法设计 → 正确性与复杂度
                    ↘ 数值表示 → 误差传播 → 稳定算法
```

## 数据结构主线

+ [[算法与复杂度]]：正确性、渐进复杂度与空间—时间折中。
+ [[线性表与抽象数据类型]]：顺序表、链表和接口与实现的分离。
+ [[栈、队列与递归]]：受限访问的线性结构及递归执行模型。
+ [[优先队列与字符串]]：堆、字符串表示和 KMP 匹配。
+ [[树与二叉树]]：遍历、搜索树、Huffman 树和并查集。
+ [[图与图算法]]：图表示、遍历、生成树与最短路。
+ [[查找与散列表]]：有序查找、树式查找和散列冲突处理。
+ [[排序算法]]：比较排序、线性时间排序与下界。

## 数值计算主线

+ [[数值误差与稳定性]]：浮点误差、条件数和算法稳定性。
+ [[线性方程组]]：消元、选主元、LU 分解和迭代法。
+ [[拟合与插值]]：最小二乘、插值多项式和样条。
+ [[非线性方程与最优化]]：求根、线搜索和梯度方法。

## 设计范式

+ [[算法设计思想]]：分治、动态规划、贪心、回溯、分支定界和随机算法。

> [!tip]
> 复习一个算法时固定回答五件事：输入与输出是什么；维护何种不变量；为什么终止且正确；时间与空间复杂度是多少；对数据分布、数值误差或实现模型有哪些前提。
