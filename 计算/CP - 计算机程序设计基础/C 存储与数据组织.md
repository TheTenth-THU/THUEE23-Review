## 存储组织主线

### 从单个对象到复合数据

C 的存储模型将类型、地址、对象寿命和数据布局连接起来。这一组的核心问题是「数据放在哪里、能存活多久、通过什么边界访问」。

### 知识依赖

+ [[数组与字符串]]从固定大小的连续存储出发，建立下标、多维布局、字符数组与边界约定。
+ [[指针与动态内存]]引入间接访问和运行时分配，要求同时维护指针来源、指向范围、寿命与权限。
+ [[结构体与自定义类型]]将多个对象组合为记录，进一步引出对齐、填充、浅复制和自引用结构。

**地址不等于有效访问权**。指针保存了一个地址值，不代表该地址仍属于存活对象，也不代表当前操作没有越界或类型违规。

## 最小示例

```c
struct Student {
    int number;
    double score;
};

struct Student *students = malloc(count * sizeof *students);
if (students == NULL) {
    return ALLOC_FAILED;
}
students[0].score = 95.0;
free(students);
students = NULL;
```

结构体规定一个元素的内部布局，动态分配决定数组对象的存储期，指针和下标负责访问连续元素。`free` 结束对象所占存储的有效期；随后把指针置空只能避免误用这一变量，不能修复其他仍指向原区域的悬空指针。
