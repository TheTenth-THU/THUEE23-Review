## 继承关系

**继承 (inheritance)** 从已有类建立新类。已有类称为**基类 (base class)**，新类称为**派生类 (derived class)**。

```cpp
class GraduateStudent : public Student {
public:
    void set_salary(double salary);

private:
    double salary_ = 0.0;
};
```

公有继承应表达「派生类是一种基类」：任何需要基类对象的地方，都能用派生类对象替代，并保持基类契约。

> [!definition] 可替换性
> 派生类不得加强基类操作的前置条件，也不得削弱后置条件或破坏基类不变量。只有满足这种行为替换，公有继承才不仅是代码复用。

## 继承方式与访问权限

继承方式改变基类 `public`、`protected` 成员在派生类中的可见级别；基类 `private` 成员始终不能被派生类直接访问，但仍存在于派生对象的基类子对象中。

```tx
| 继承方式 | 基类 `public` 成员 | 基类 `protected` 成员 | 基类 `private` 成员 |
|:---------|:-------------------|:----------------------|:--------------------|
| `public` | 在派生类中仍为 `public` | 仍为 `protected` | 不可直接访问 |
| `protected` | 变为 `protected` | 仍为 `protected` | 不可直接访问 |
| `private` | 变为 `private` | 变为 `private` | 不可直接访问 |
```

`class Derived : Base` 默认是私有继承；`struct Derived : Base` 默认是公有继承。若意图表达接口替换，应显式写 `public`。

## 构造与析构顺序

派生类不能依赖「继承来的构造函数」自动初始化新增成员。构造派生对象时，顺序为：

1. 虚基类子对象。
2. 直接基类子对象，按声明顺序。
3. 数据成员，按声明顺序。
4. 派生类构造函数体。

析构顺序完全相反。派生类通过初始化列表调用直接基类构造函数：

```cpp
GraduateStudent::GraduateStudent(int id, std::string name, double salary)
    : Student(id, std::move(name)), salary_(salary)
{
}
```

## 名字隐藏与作用域

派生类声明与基类同名的成员会隐藏基类中的整组同名声明，即使参数不同。可用 `using Base::function;` 把基类重载集合引入派生类作用域。

同名成员可用限定名 `Base::member` 明确访问。名字查找、访问控制和虚函数动态分派是不同阶段的规则，应分别判断。

## 公有、保护与私有继承

+ 公有继承表达接口上的「是一种」。
+ 私有继承表示实现复用，外部看不到基类接口。
+ 保护继承也隐藏公共接口，但允许更下层派生类继续访问。

实现复用通常优先使用组合，因为组合暴露更少耦合，并能独立更换成员实现。

> [!tip] 组合优先
> 若只需要复用实现，或新类型不能满足基类契约，使用成员对象表达「有一个」，不要使用公有继承伪装成「是一种」。

## 多重继承

一个派生类可拥有多个直接基类。多重继承适合组合多个正交接口，但会带来同名成员二义性和重复基类子对象。

若继承图形成菱形，最下层对象可能包含两份共同基类子对象。通过**虚继承 (virtual inheritance)** 可让最下层对象共享一份虚基类子对象；最终派生类负责初始化虚基类。

多重继承增加布局和构造顺序复杂度，应优先用于纯接口或职责正交的基类。

## 继承与对象切片

把派生对象按值赋给基类对象，只复制其基类子对象，派生部分被丢弃，称为**对象切片 (object slicing)**。需要保留动态类型时，应通过基类引用或指针操作。

这也是运行时多态必须依赖引用或指针的原因，详见 [[多态与虚函数]]。
