## 地址与间接访问

**指针 (pointer)** 是能表示对象或函数地址的值。`&` 取得对象地址，`*` 对有效指针进行间接访问。

```c
int value = 42;
int *pointer = &value;
*pointer = 43;
```

指针的类型决定解引用结果和指针算术步长。`int *` 指向 `int`，`int **` 指向保存 `int *` 的对象，二者不可混淆。

> [!definition] 空指针
> 空指针不指向任何对象或函数。它可用于表示「无目标」，但不能解引用。C 中可用 `NULL` 或整数常量 `0` 产生空指针常量。

## 指针有效性的四个条件

解引用指针前至少要确认：

+ 指针非空。
+ 指针指向的对象仍在生命周期内。
+ 地址满足目标类型的对齐要求。
+ 访问没有越过对象或数组边界，且读写权限正确。

未初始化指针、悬空指针、越界指针和错误类型转换都可能破坏这些条件。

## 指针算术

指针加减只在同一数组对象及其尾后位置范围内有定义。若 `p` 指向数组元素，则 `p + i` 跨过 $i$ 个元素。

同一数组中的两个指针相减得到元素距离，结果类型为 `ptrdiff_t`。对无关对象的指针比较大小或相减没有可移植语义。

`void *` 可与任意对象指针相互转换，但不能直接解引用；必须先转换为正确的目标类型。函数指针不属于对象指针，不能依赖二者可互换。

## 指针与 `const`

限定位置决定约束对象：

```c
const int *read_only;      /* 不能通过该指针修改 int */
int *const fixed_target = &value; /* 指针自身不能改指向 */
```

`const int *const` 同时限制间接修改和改指向。把接口参数声明为指向 `const` 的指针，可以表达函数只读数据的契约。

## 动态存储

动态内存由 `<stdlib.h>` 中的函数管理：

+ `malloc` 分配指定字节数，内容未初始化。
+ `calloc` 分配元素数组，并把所有字节置零。
+ `realloc` 调整已有分配大小，必要时移动内容。
+ `free` 释放先前获得的动态存储。

```c
int *data = malloc(count * sizeof *data);
if (data == NULL) {
    return ALLOCATION_FAILED;
}
/* 使用 data。 */
free(data);
data = NULL;
```

计算分配大小前应检查乘法溢出：若 `count > SIZE_MAX / sizeof *data`，则不能安全计算总字节数。

> [!danger] `realloc` 的正确接收方式
> `realloc` 失败时保留原分配并返回空指针。应先用临时指针接收结果，成功后再更新原指针，否则会丢失原分配地址。

## 所有权与生命周期

动态对象从分配成功开始存活，直到被 `free` 释放。接口应说明谁拥有分配、谁负责释放、借用指针可使用多久。

常见缺陷包括：

+ **内存泄漏**：失去最后一个可释放分配的指针。
+ **重复释放**：对同一分配调用多次 `free`。
+ **释放后使用**：对象生命周期结束后仍通过旧指针访问。
+ **错误释放**：释放非动态对象、内部地址或已偏移的指针。

把指针设为空不能修复其他仍存在的悬空别名，因此关键是建立清晰的所有权约定。

## 指针参数与输出参数

指针参数可传递可变对象、数组和输出位置。若函数需要改变调用者保存的指针本身，应传入二级指针：

```c
int allocate_buffer(size_t count, int **output);
```

接口应先验证 `output`，只在成功时写入新指针，并明确失败时其值是否保持不变。

## 指针与数组辨析

数组和指针在表达式中关系密切，但并非同一种对象：

+ 数组自身包含全部元素，指针对象只保存一个地址值。
+ `sizeof array` 得到整个数组大小，`sizeof pointer` 得到指针大小。
+ 数组名不能赋值，普通指针变量可以改变指向。

> [!tip] 总是携带边界
> 用「指针＋长度」描述一段连续区域，用「起始指针＋尾后指针」描述半开区间。任何只传裸指针而不约定边界的接口都需要额外审查。
