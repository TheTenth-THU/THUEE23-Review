## 类的基本模型

**类 (class)** 定义一类对象共有的状态表示、允许的操作和不变量；**对象 (object)** 是该类的具体实例。

```cpp
class Counter {
public:
    explicit Counter(int initial = 0) : value_(initial) {}
    void increment() { ++value_; }
    int value() const { return value_; }

private:
    int value_;
};
```

数据成员保存状态，成员函数定义行为。公开成员形成接口，私有成员保存实现细节。

> [!definition] 封装
> **封装 (encapsulation)** 是把对象状态与维护该状态的操作绑定在一起，并通过访问控制限制外部直接破坏类不变量。

## 访问控制

+ `public` 成员构成类的公开接口，可由使用者访问。
+ `private` 成员只能由类的成员和友元直接访问。
+ `protected` 成员还允许派生类成员访问，主要服务于继承层次。

`class` 的默认成员访问权限为 `private`，`struct` 的默认权限为 `public`；除此之外，二者都能拥有成员函数、构造函数和继承关系。

访问控制是编译期规则，不等于加密。设计目标是让所有合法操作都经过维护不变量的接口。

## 对象与成员访问

对象使用 `.` 访问成员，对象指针使用 `->`：

```cpp
Counter counter(3);
counter.increment();

Counter *pointer = &counter;
pointer->increment();
```

每个非静态成员函数都有一个隐式的 `this` 指针，指向调用该函数的对象。成员访问可理解为通过 `this` 完成。

`const` 成员函数承诺不通过该对象修改其逻辑状态：

```cpp
int value() const;
```

只有 `const` 成员函数能直接在 `const` 对象上调用。应把观察操作标记为 `const`，使接口表达读写意图。

## 类的声明与定义

类定义通常放在头文件，使所有使用者看到完整类型；较长成员函数定义放在源文件中。类体内定义的成员函数隐式具有 `inline` 语义，但是否真正展开由编译器决定。

成员函数在类外定义时使用作用域解析运算符：

```cpp
int Counter::value() const
{
    return value_;
}
```

## 对象间协作

对象通过成员调用、函数参数和返回值协作。接口可按语义选择：

+ 值参数表示函数需要一个独立副本。
+ `const T&` 表示只读借用并避免复制。
+ `T&` 表示可变借用，调用者必须提供有效对象。
+ 指针表示目标可为空或需要指针语义；应明确所有权。

> [!danger] Getter 与 Setter 不是自动封装
> 若类只是为每个数据成员提供无条件读写接口，外部仍可任意破坏组合约束。公开操作应表达领域动作，例如 `withdraw(amount)`，而不是仅暴露 `set_balance(value)`。

## 友元

类可声明函数或其他类为**友元 (friend)**，使其访问私有和保护成员。友元常用于需要对称转换的非成员运算符或紧密协作类型。

友元不是成员，不受成员访问限定符影响，也不会被继承。它扩大了可访问实现的范围，应保持少量且目的明确。

## 静态成员

静态数据成员由全类对象共享，不属于任何单个对象；静态成员函数没有 `this` 指针，只能直接访问静态成员。

共享计数、缓存或注册表可用静态成员表示，但它们本质上是全局状态的一种受控形式，需要考虑初始化顺序、线程安全和测试隔离。

对象从建立到销毁的完整语义见 [[对象生命周期与资源管理]]。
