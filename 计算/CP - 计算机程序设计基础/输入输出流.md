## 流抽象

**流 (stream)** 把数据传输抽象为有序字符或字节序列。C++ 标准库用统一接口处理终端、文件和内存字符串。

+ `std::cin` 是标准输入流。
+ `std::cout` 是标准输出流。
+ `std::cerr` 用于及时输出错误信息。
+ `std::clog` 用于带缓冲的日志信息。

流插入 `<<` 把值写入输出流，流提取 `>>` 从输入流解析值。运算符返回流引用，因此可链式调用。

## 格式化输入输出

`<iomanip>` 中的操纵器可控制字段宽度、精度、进制和浮点格式：

```cpp
std::cout << std::fixed << std::setprecision(2) << value;
```

`std::setw` 通常只影响紧随其后的一个字段，而 `std::fixed`、精度和进制等状态会保留。公共函数若临时改变共享流格式，应保存并恢复必要状态。

## 流状态

流用状态位记录最近操作结果：

+ `goodbit` 表示无错误。
+ `eofbit` 表示遇到输入结束。
+ `failbit` 表示格式解析失败等可恢复错误。
+ `badbit` 表示底层 I/O 等严重错误。

流对象可在条件中测试成功与否：

```cpp
int value;
while (std::cin >> value) {
    process(value);
}
```

> [!danger] 失败状态会保持
> 格式解析失败后，后续读取会继续失败，直到调用 `clear()` 清除状态，并从输入缓冲中移除导致失败的字符。

`operator>>` 默认跳过前导空白并在下一个空白处停止。读取整行使用 `std::getline`；在格式化提取后立刻调用 `getline` 时，要处理缓冲区中残留的换行符。

## 文件流

`std::ifstream`、`std::ofstream` 和 `std::fstream` 分别提供文件输入、输出和双向访问。文件流对象遵循 RAII，析构时自动关闭文件。

```cpp
std::ifstream input("data.txt");
if (!input) {
    throw std::runtime_error("cannot open data.txt");
}
```

打开模式包括 `std::ios::in`、`out`、`app`、`ate`、`trunc` 和 `binary`，可用位或组合。输出模式可能截断文件，必须明确选择。

文本流执行格式化和可能的换行转换；二进制流按字节传输，但直接写入对象内存仍不构成可移植格式。

## 字符串流

`std::istringstream` 从字符串解析，`std::ostringstream` 构造字符串，`std::stringstream` 支持双向操作。它们适合把文本解析与外部 I/O 分离：

```cpp
std::istringstream line_stream(line);
int id;
double score;
if (line_stream >> id >> score) {
    /* 使用解析结果。 */
}
```

## 自定义类型的流运算

流插入通常接收 `const` 引用，流提取接收可变引用：

```cpp
std::ostream& operator<<(std::ostream& output, const Point& point);
std::istream& operator>>(std::istream& input, Point& point);
```

提取函数应先把数据读入临时变量，验证全部约束后再修改目标对象。若输入无效，应设置 `failbit` 并保持对象原值。

> [!tip] 输出应可组合
> `operator<<` 不应擅自输出换行，也不应把信息写入其他流。让调用者决定分隔符和行结构，才能保持链式组合能力。

## 缓冲与刷新

输出通常先进入缓冲区。`std::endl` 同时输出换行并刷新，频繁使用会产生不必要开销；只需换行时使用 `'\n'`。

程序正常终止或流析构会刷新缓冲，但写入错误仍需检查。对持久数据，关闭成功不等于已经满足更强的磁盘持久性保证。

## 流与异常

流默认通过状态位报告大多数错误，也可用 `exceptions()` 指定哪些状态触发异常。无论选择状态检查还是异常，接口都应统一错误策略，详见 [[异常处理]]。
