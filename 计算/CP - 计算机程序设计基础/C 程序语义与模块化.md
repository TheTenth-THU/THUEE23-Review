## 行为组织主线

### 从表达式到翻译单元

C 程序的行为骨架由类型、表达式、控制流和函数共同构成。它们分别回答「值如何表示与运算」、「语句按什么顺序执行」以及「行为如何分解与复用」。

### 知识依赖

+ [[C 数据类型与表达式]]先建立对象表示、运算规则、类型转换、存储期与链接的基础。
+ [[C 控制结构]]在表达式求值之上组织分支、循环和提前退出，并用不变量检查算法正确性。
+ [[函数与模块化]]再将控制过程封装为具有参数、返回值和副作用契约的函数，并通过头文件与翻译单元建立模块边界。

**与存储组织的边界**：本组关注「程序执行什么」以及「行为如何组织」；数组、指针、动态内存和聚合类型则集中放在 [[C 存储与数据组织]]。

## 最小示例

```c
int clamp(int value, int lower, int upper)
{
    if (value < lower) {
        return lower;
    }
    if (value > upper) {
        return upper;
    }
    return value;
}
```

这个函数把三个层次压缩在一个接口中：参数与返回值由类型约束，两个 `if` 决定控制流，函数名与签名向调用者隐藏具体分支。若没有 `lower <= upper` 的前置条件，接口语法仍合法，但函数契约不完整。
