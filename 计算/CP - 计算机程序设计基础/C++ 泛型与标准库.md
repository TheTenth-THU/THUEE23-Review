## 泛型与标准库主线

### 编译期抽象与通用接口

**泛型编程 (generic programming)** 把类型作为参数，让数据结构和算法在保留静态类型检查的同时复用。标准库则以容器、迭代器、算法和流等组件提供经过约定的通用接口。

### 两个知识单元

+ [[模板与容器]]从函数模板、类模板与实例化出发，进入标准容器、迭代器和算法的协作模型。
+ [[输入输出流]]用统一的流状态与格式化接口处理控制台、文件和字符串，并通过运算符重载扩展自定义类型。

**与面向对象的关系**：模板主要在编译期根据类型实例化代码，虚函数则主要在运行时根据对象的动态类型分派。两者是并列的多态机制，不应将泛型编程等同于面向对象。

## 最小示例

```cpp
template<class Range>
void print_sorted(Range values, std::ostream& output)
{
    std::sort(values.begin(), values.end());
    for (const auto& value : values) {
        output << value << ' ';
    }
}
```

模板让函数适用于满足迭代与排序要求的不同容器；`std::sort` 通过迭代器访问序列；`std::ostream` 让输出目标可以是终端、文件或字符串流。按值接收 `values` 还明确表示排序只作用于副本，不改变调用者的原容器。
