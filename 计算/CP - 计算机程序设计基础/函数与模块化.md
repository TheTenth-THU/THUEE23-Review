## 函数抽象

**函数 (function)** 把一段计算封装为可命名、可调用的单元。函数签名描述返回类型、函数名和参数类型，函数体给出具体实现。

```c
double average(const double values[], size_t count);
```

上式是函数声明。声明使调用处能够进行类型检查；函数定义还要提供函数体，并且整个程序中只能有一个满足外部链接要求的定义。

> [!definition] 函数契约
> 函数契约由前置条件、后置条件和副作用组成。前置条件约束合法参数，后置条件描述返回后的保证，副作用说明对外部状态的修改。

## 参数传递与返回

C 只进行**值传递 (pass by value)**。调用函数时，形参获得实参值的副本；修改形参本身不会改变调用者对象。

若要修改调用者对象，应传入其地址：

```c
void swap_int(int *left, int *right)
{
    int temporary = *left;
    *left = *right;
    *right = temporary;
}
```

这里复制的仍然是指针值，但通过指针间接访问了调用者对象。接口还应规定指针能否为空、指向几个有效对象以及是否允许别名。

函数返回对象值时，返回值传回调用者；不能返回指向已结束生命周期的自动局部对象的指针。

## 数组参数

函数参数列表中的数组形式会调整为指针类型：

```c
void process(int values[], size_t count);
void process(int *values, size_t count);
```

两种声明在参数类型上等价。函数内的 `sizeof(values)` 得到指针大小，而不是调用者数组大小，因此必须显式传入 `count`。

二维数组参数除第一维外，需要给出后续维度，或把数据展平并显式传递行列数。

## 调用栈与递归

一次函数调用通常建立一个**栈帧 (stack frame)**，保存参数、自动局部对象、返回地址和调用现场。函数返回后，其栈帧失效。

**递归 (recursion)** 是函数直接或间接调用自身。正确递归必须具有：

+ 能直接求解的基例。
+ 把问题缩小的递归步骤。
+ 保证到达基例的度量。

```c
unsigned long long factorial(unsigned int n)
{
    return n <= 1 ? 1 : n * factorial(n - 1);
}
```

> [!danger] 递归深度
> 每层递归通常消耗栈空间。深度不受控制会导致栈溢出；线性递归若可自然改写为循环，循环往往更容易控制资源。

## 作用域与静态对象

块作用域对象只在块内可见。文件作用域对象和函数可通过 `static` 获得内部链接，把名字限制在当前翻译单元。

函数内的 `static` 局部对象具有静态存储期，只初始化一次，但名字仍局限于块内。它能在多次调用之间保存状态，也会引入隐藏依赖、重入和并发访问问题。

`extern` 声明通常表示实体的定义位于其他位置。应在头文件中放共享声明，在某个源文件中放唯一外部定义。

## 模块化设计

**模块化设计 (modular design)** 按「自顶向下、逐步求精」把系统拆成职责清晰的模块。模块接口稳定，内部实现可独立替换。

典型 C 模块包含：

+ 头文件：公开类型、宏常量和函数声明。
+ 源文件：函数定义与私有辅助对象。
+ 测试文件：只通过公开接口验证模块契约。

头文件应使用包含保护：

```c
#ifndef VECTOR_H
#define VECTOR_H

double vector_norm(const double *data, size_t count);

#endif
```

> [!note] `#include` 的含义
> `#include` 在预处理阶段把指定文件内容纳入当前翻译单元。它不是运行时调用，也不会自动链接相应实现。

## 宏与内联函数

对象式宏常用于条件编译或兼容旧接口；函数式宏只是文本替换，参数可能被多次求值：

```c
#define SQUARE(x) ((x) * (x))
```

调用 `SQUARE(i++)` 会产生危险的重复副作用。可以使用函数时，应优先选择普通函数或 `inline` 函数，让编译器进行类型检查并保证参数只求值一次。

## 函数指针

函数指针把行为作为数据传递，可用于回调、排序比较器和状态分派：

```c
int compare_int(const void *left, const void *right);
int (*compare)(const void *, const void *) = compare_int;
```

函数指针类型必须与目标函数兼容。复杂声明可用 `typedef` 简化，以便接口突出语义而不是语法细节。
