## 数组及连续存储

**数组 (array)** 是由固定数量、相同类型元素组成的连续存储对象。若数组长度为 $n$，有效下标为 $0,1,\ldots,n-1$。

```c
int values[4] = {2, 4, 6, 8};
```

数组名在大多数表达式中转换为指向首元素的指针，但存在重要例外：作为 `sizeof`、一元 `&` 的操作数，或用字符串字面量初始化字符数组时，不发生该转换。

> [!danger] 越界没有自动检查
> 访问 `values[4]` 不会形成一个合法的「尾后元素对象」。可以构造尾后指针用于比较，但不能解引用它。越界读写属于未定义行为。

## 下标与指针的关系

下标运算定义为：

$$
a[i]\equiv *(a+i).
$$

这里的加法按元素大小缩放。`a + i` 指向第 $i$ 个元素，而不是地址数值简单增加 $i$ 个字节。

数组对象不能整体赋值。需要复制数组内容时，应逐元素复制或使用适当的库函数，并确认源、目标大小和重叠条件。

## 多维数组

C 的二维数组本质上是「元素为数组的数组」，按行连续存储：

```c
int matrix[3][4];
```

`matrix` 转换后是指向「含 4 个 `int` 的数组」的指针，类型可写为 `int (*)[4]`；`matrix[i]` 是第 $i$ 行数组，并在多数表达式中继续转换为该行首元素指针。

因此：

$$
matrix[i][j]\equiv *(*(matrix+i)+j).
$$

向函数传入二维数组时，编译器必须知道每行宽度，才能计算跨行步长。

## 字符数组与字符串

C 的**字符串 (string)** 是以空字符 `\0` 结尾的字符序列。字符数组只有在其有效范围内存在终止空字符时，才能作为 C 字符串使用。

```c
char word[] = "China";
```

该数组包含 6 个元素，最后一个元素为 `\0`。字符串长度 `strlen(word)` 为 5，而数组占用空间 `sizeof word` 为 6。

> [!danger] 容量与长度
> 长度是不含终止空字符的字符数，容量是数组可容纳的元素数。存放长度为 $n$ 的 C 字符串至少需要 $n+1$ 个字符空间。

## 常用字符串操作

`<string.h>` 提供 `strlen`、`strcmp`、`strcpy`、`strcat`、`memcpy` 和 `memmove` 等函数。

+ `strcmp` 按字典序比较，返回负数、零或正数，不能假设返回值恰为 $-1$、$0$ 或 $1$。
+ `strcpy` 和 `strcat` 不知道目标容量，调用者必须预先保证空间足够。
+ `memcpy` 要求源和目标区域不重叠；可能重叠时使用 `memmove`。
+ `strlen` 必须扫描到 `\0`，对未终止缓冲区调用会越界读取。

可写接口应同时接收目标缓冲区与容量，并把截断、失败和终止策略写入契约。

## 字符输入

读取一行时，`fgets` 比不受限的字符串输入更安全：

```c
char line[128];
if (fgets(line, sizeof line, stdin) != NULL) {
    line[strcspn(line, "\n")] = '\0';
}
```

格式化输入 `%s` 默认跳过前导空白，并在下一个空白处停止；若使用 `scanf` 读入字符数组，必须给出宽度限制，为终止空字符预留空间。

## 字符编码

`char` 保存一个字节，但一个用户可见字符未必只占一个字节。ASCII 字符在常见编码中通常保持单字节；UTF-8 用 1 至 4 个字节编码一个 Unicode 码点，一个字形还可能由多个码点组成。

因此，字节数、码点数和用户可见字符数是三个不同概念。`strlen` 返回字节长度，不是中文字符个数。

> [!note] 文本边界
> 程序内部应明确使用的编码，并只在输入输出边界进行解码与编码。不要按字节截断 UTF-8 文本，否则可能切断一个多字节序列。
