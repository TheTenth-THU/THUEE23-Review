## 知识地图

程序设计把问题求解过程变成计算机可以执行的精确步骤。其核心链条为

$$
\text{问题建模}\longrightarrow\text{算法与数据表示}\longrightarrow\text{源程序}\longrightarrow\text{可执行程序}\longrightarrow\text{测试与修正}.
$$

+ [[程序设计与构建流程]]说明算法描述、程序结构、翻译系统、调试与测试，是两条语言主线的共同入口。
+ [[C 语言基础]]以过程和函数组织计算，重点掌握数据表示、控制流、内存访问与文件接口。
    + [[C 数据类型与表达式]]讨论对象表示、类型转换和运算规则。
    + [[C 控制结构]]把顺序、分支与循环组织为可验证的算法。
    + [[函数与模块化]]通过函数、作用域和翻译单元控制复杂度。
    + [[数组与字符串]]讨论连续存储、下标访问和以空字符结尾的字符串。
    + [[指针与动态内存]]连接地址、间接访问、参数传递和资源生命周期。
    + [[结构体与文件]]用聚合类型描述记录，并通过流完成持久化输入输出。
+ [[C++ 面向对象程序设计]]将数据与操作封装为对象，并进一步引出继承、多态和泛型编程。
    + [[类与对象]]建立封装、访问控制和成员调用的基本模型。
    + [[对象生命周期与资源管理]]统一构造、复制、赋值和析构。
    + [[运算符重载]]让类对象获得与其抽象一致的表达式语义。
    + [[继承与派生]]组织类之间的复用与扩展关系。
    + [[多态与虚函数]]通过统一接口实现运行时替换。
    + [[输入输出流]]把格式化、文件和字符串输入输出统一为流接口。
    + [[异常处理]]分离异常发现与恢复策略。
    + [[模板与容器]]以类型参数和标准容器支持泛型程序设计。
