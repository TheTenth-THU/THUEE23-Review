## 自定义数据布局

### 聚合数据类型

**结构体 (structure)** 把若干可能不同类型的成员组合为一个记录。结构体类型描述数据布局，对象保存具体成员值。

```c
struct Student {
    int number;
    char name[32];
    double score;
};
```

对象用 `.` 访问成员，结构体指针用 `->` 访问成员。结构体对象可整体赋值、作为函数参数或返回值，但其中若含指针，整体赋值只复制地址值，不会自动复制所指资源。

> [!danger] 浅复制
> 含拥有型指针的结构体若直接赋值，两个对象可能指向同一动态内存。必须明确禁止复制、实现深复制，或把资源所有权移交规则写入接口。

### 对齐与填充

编译器可能在成员之间或结构体末尾加入填充，使每个成员满足对齐要求。因此，`sizeof(struct T)` 不一定等于各成员大小之和。

结构体对象的内存布局受实现和 ABI 影响，不应把内存字节直接当成稳定文件格式或网络协议。持久化时应逐字段编码，并明确字节序、宽度和版本。

### 联合体、枚举与 `typedef`

**联合体 (union)** 的所有成员共享同一存储，大小足以容纳最大成员。程序必须跟踪当前哪个成员有效，常用「枚举标签＋联合体」表示带标签变体。

**枚举 (enumeration)** 为一组整数常量命名，适合表示有限状态。`typedef` 为已有类型引入别名，不创建新的独立类型。

## 递归数据结构

### 自引用结构

结构体可以含有指向自身类型的指针，从而构造链表、树和图节点：

```c
struct Node {
    int value;
    struct Node *next;
};
```

不能直接包含自身类型对象，否则大小定义无限递归；通过指针则只需固定的地址存储。

结构体的内存布局不等于稳定的外部数据格式。将聚合数据持久化时，还需另行设计字段编码与错误处理，见 [[C 输入输出与文件#二进制输入输出]]。
