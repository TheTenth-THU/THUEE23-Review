## 结构化控制流

C 用顺序、选择和循环三类结构表达算法。所有结构都应有明确的入口、出口和状态变化。

**复合语句 (compound statement)** 用一对花括号把多条声明和语句组成一个块。即使分支或循环体只有一条语句，也建议保留花括号，以降低后续修改引入错误的风险。

## 选择结构

`if` 根据标量表达式的真假选择路径。数值零和空指针为假，其他标量值为真。

```c
if (score >= 60) {
    passed = 1;
} else {
    passed = 0;
}
```

`switch` 适合依据一个整数或枚举值进行离散分派。`case` 标签必须是整数常量表达式；若不希望继续执行下一分支，应显式写 `break`。

> [!danger] 悬空的 `else`
> `else` 与语法上最近且尚未匹配的 `if` 配对。通过花括号明确层级，不要依赖缩进猜测语法。

## 循环结构

`while` 先判断条件，适合迭代次数由状态决定的循环；`do...while` 至少执行一次循环体；`for` 把初始化、条件和更新集中书写，适合计数循环。

```c
size_t sum = 0;
for (size_t i = 0; i < n; ++i) {
    sum += values[i];
}
```

该循环可用不变量描述：第 $i$ 次迭代开始时，`sum` 等于前 $i$ 个元素之和。初始化使不变量对 $i=0$ 成立，循环体保持不变量，终止时 $i=n$，因而得到全部元素之和。

## `break`、`continue` 与 `return`

+ `break` 终止最内层循环或 `switch`。
+ `continue` 跳过本轮剩余语句并进入下一次条件判断或更新。
+ `return` 立即结束当前函数，并可向调用者返回值。

这些跳转应服务于清晰的控制结构。多层循环需要同时退出时，可以把循环封装为函数并用 `return`，或使用显式状态变量。

## 哨兵、计数与状态机

常见循环可分为：

+ **计数控制**：预先知道迭代次数。
+ **哨兵控制**：读到特定值或输入结束时终止。
+ **状态控制**：根据系统状态转移，直至到达终止状态。

输入驱动循环应把「读取是否成功」放在条件中，而不是先使用数据再检查：

```c
int value;
while (scanf("%d", &value) == 1) {
    process(value);
}
```

## 循环正确性与终止性

证明循环正确通常包含三步：

1. **初始化**：首次迭代前不变量成立。
2. **保持**：若某轮开始时成立，执行循环体后下一轮仍成立。
3. **终止**：循环终止条件与不变量共同推出目标结论。

还需给出严格推进的变元，例如每轮减少的非负整数，证明循环最终终止。

> [!danger] 常见边界错误
> `i <= n` 与 `i < n` 的区别必须由有效下标范围决定。长度为 $n$ 的数组有效下标为 $0$ 到 $n-1$；空输入和单元素输入都应单独测试。

## 控制流与副作用

条件表达式中混入赋值、递增或函数副作用会降低可读性。除惯用的输入循环外，应优先把状态更新拆成独立语句。

对同一对象的多个修改若缺乏规定的先后关系，可能产生未定义行为。例如，不应写依赖复杂求值顺序的自增表达式。控制流清晰不仅是风格要求，也是语义安全的一部分。
