**原题**

+ 「Python 与 C++ 有什么不同？」 ([2021](test/2021-八字班推研面经-涂晨昕.docx)) 〔A/B 级〕

**参考解答**

**分析**

这组问题包含 1 条原题或连续追问。作答时应按提问顺序覆盖，不能只解释最后出现的术语。

+ 对 「Python 与 C++ 有什么不同？」，需要先给出准确概念，再说明核心关系、成立条件和典型用途。

**解答**

Python 以动态类型和自动内存管理为主，常由字节码解释器执行，开发快且生态丰富；C++ 静态类型、通常提前编译为本地代码，能精细控制对象布局、所有权与性能。两者都支持面向对象和泛型风格，不能简单概括为「一个解释、一个编译」，因为实现可使用 JIT、扩展模块或解释器。

+ 「Python 的 `list` 和 `tuple` 有什么区别？哪个效率更高？」 ([2021](test/2021-八字班推研面经-涂晨昕.docx)) 〔A 级〕

**参考解答**

**分析**

这组问题包含 1 条原题或连续追问。作答时应按提问顺序覆盖，不能只解释最后出现的术语。

+ 对 「Python 的 `list` 和 `tuple` 有什么区别？哪个效率更高？」，需要在定义、机制、代价和适用场景上逐维比较，不能只罗列名词。

**解答**

`list` 可变，可增删改元素；`tuple` 不可变，若所有元素可哈希则自身可作字典键。CPython 中 tuple 结构更紧凑，创建和迭代常略快，但差异依实现和场景而定，不能把「更高效」当作选型的唯一理由。
