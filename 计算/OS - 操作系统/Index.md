## 课程知识地图

操作系统把处理器、内存和 I/O 设备抽象为可共享、可保护的资源，并向应用提供稳定接口。课程从操作系统的职责与结构出发，依次研究并发执行、存储抽象、设备传输和持久化数据，形成「抽象对象—管理机制—调度策略—故障与权衡」的知识主线。

## 知识点导航

+ **[[操作系统引论]]**：从扩展机器、资源管理者和用户接口三个视角理解操作系统，建立并发、共享、虚拟和异步四个基本特征，再比较单体、分层、微内核与客户—服务器等体系结构。
+ **[[处理机管理]]**：围绕 CPU 共享建立从执行实体到协调与调度的完整链条。
    + **[[进程]]**：由程序并发执行的问题引出进程和 PCB，再研究三态、五态、七态模型及进程控制原语。
    + **[[线程]]**：分离资源分配与调度执行，比较用户级、内核级和混合线程实现的开销与阻塞行为。
    + **[[进程间通信]]**：从临界区问题推进到软件互斥、硬件原子指令、信号量、管程和高级 IPC，并用经典同步问题检验正确性。
    + **[[处理机调度]]**：比较批处理、交互式和实时调度目标，并研究死锁的条件、预防、避免、检测与解除。
+ **[[存储器管理]]**：围绕地址空间、重定位、保护和扩充建立内存抽象。
    + **[[连续分配存储管理]]**：比较固定分区、动态分区、紧缩和伙伴系统的空间利用与管理开销。
    + **[[页式分配存储管理]]**：从页表与 TLB 进入虚拟存储、缺页处理、页面置换和工作集模型。
+ **[[设备管理]]**：连接设备控制器、中断与 DMA、I/O 软件层次、缓冲、SPOOLing、磁盘调度和 RAID。
+ **[[文件管理]]**：从文件和目录抽象推进到逻辑与物理组织、空间分配、共享保护及一致性维护。
