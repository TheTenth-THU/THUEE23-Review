# LA - 线性代数

## 来源核对

+ 2020 `推研面经-3` 明确出现矩阵特征值与奇异值比较；2024 高思研明确出现特征向量与 LTI 特征函数的联系。
+ 2014 二字班面经明确询问条件数和如何避免线性方程组病态，并记录了选主元这一回答；解答需纠正「选主元能改变问题条件数」的误解。
+ 2009 与 2012 分类面经记录计算机组出现 Gaussian 消元；2018 直接询问特征降维，2019 间接记录计算机组出现 PCA。
+ 旧可逆判据、秩、一般对角化、实对称矩阵、SVD 通用介绍和 CSR 均找不到所列实际来源，主要来自 yj 备考材料，不作为原题。

## 迁移计划

+ 按谱结构、数值线性代数、低维表示重写为 5 题。
+ PCA 与 MC 双向标注；特征函数与 SS 双向标注。
+ 2018「所有 Gaussian 内容」跨越消元、分布、随机过程和信道，不硬塞入 LA，留到综合题库统一处理。

## 迁移结果

+ 重写为 5 题；删除只有备考材料支持的可逆判据、一般对角化、实对称矩阵性质、SVD 通用介绍和 CSR 原题。
+ PCA 已与 MC 双向标注；特征向量/特征函数已标注同时属于 SS，待处理 SS 时补齐对向题。
+ 条件数解答明确区分问题病态与算法稳定性，纠正「选主元能改变条件数」的面经作答误区。
