# PS - 统计信号处理基础

## 来源核对

+ 课程原先没有 `QUESTIONS.md`；相关问题分散在概率论、通信与信号系统旧题库中。
+ 2018—2022 面经实际记录先验、后验、条件概率、Bayes 公式、MLE、MAP 与无偏性；没有把课程复习提纲扩写成原题。
+ 2019、2021 面经记录重复发送后的信噪比与容量追问；2012 面经记录匹配滤波及 FFT 实现；2023 李响面经记录 Neyman–Pearson 准则。
+ 2024 高思研面经记录二维图像加入 $-1$、$1$ 噪声后能否使用 Wiener 滤波，需区分加性双极噪声与椒盐替换噪声。

## 迁移计划

+ 按 Bayes 参数估计、观测合并与最佳接收、假设检验组织题库。
+ 与 PR、CN、SS 共有的题目均保留在 PS，并在原题末尾标明其他所属课程。
+ 回答中明确估计与检测、先验与似然、合并信噪比与信道容量之间的层次差异。

## 迁移结果

+ 新建并扩充为 6 题，覆盖全部已核实的统计信号处理面试回忆题。
+ 匹配滤波题补充白噪声最优性、有色噪声预白化和 FFT 线性卷积实现；重复观测题补充独立性、相关噪声与最大比合并条件。
+ 结构、来源路径和正式笔记标题校验通过；已在 CN、SS 和 VI 中补齐相应多课程记录。
