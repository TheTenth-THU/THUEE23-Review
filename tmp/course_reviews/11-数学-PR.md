# PR - 概率论与随机过程

## 来源核对

+ 2012 分类面经与孟越个人面经记录了 Markov 链转移概率、平稳转移概率、Poisson 过程的 Markov 性、边缘正态与联合正态，以及均匀分布输入通过 LTI 系统后的分布问题。
+ 2013 黄博与魏特面经记录了 Poisson 过程的定义、样本轨道、宽平稳性、计数过程身份，以及每日进入超市人数能否采用 Poisson 模型。
+ 2017 陈誉博面经记录了 Gaussian 函数卷积和两个标准正态密度卷积后的方差；2018 总体面经进一步记录概率公理、Gaussian 变量之差与卷积，以及先验、后验和条件概率。
+ 2019 面经记录中心极限定理、独立与不相关的区别及联合 Gaussian 条件；2020 面经记录 Bayes 公式、MLE、MAP、无偏性辨析和均匀变量之和；2022 再次出现 MLE 与 MAP 的区别。
+ 2023 李响面经记录 Neyman–Pearson 准则；2024 zcy、吴凌沨面经记录大数定律、中心极限定理、宽平稳与严平稳；2025 ljh、wj 面经记录顺序概率、Gaussian 和差的方差、随机变量与随机过程及平稳性。
+ 旧题库把 2024 yj 压缩包内的 `问题answer.md`、`问题answer2.md` 和 `核心课复习.md` 当作实际面经来源，产生了「Gaussian 分布为什么重要」「通用大数定律」等伪原题；本次只采用压缩包内实际面经正文，备考答案不作为原题证据。

## 迁移计划

+ 按概率基础与统计推断、极限定理与顺序概率、Gaussian 结构、随机过程、Poisson 与 Markov、统计检测重写。
+ Gaussian 函数卷积、均匀随机输入通过 LTI 系统的问题与 SS 双向标注；MLE、MAP、NP 准则与 PS 双向标注。
+ 对题目没有给出独立性或联合 Gaussian 条件的情形，显式保留协方差项并说明不能仅由边缘分布推出和差仍为 Gaussian。

## 迁移结果

+ 重写并扩充为 17 题，所有题目均回到实际面经或早年分类面经核对；处理 SS 时同步补入多次卷积的中心极限定理解释和功率谱问题。
+ 明确区分边缘 Gaussian、联合 Gaussian、独立和不相关；Gaussian 和差与均匀变量之和均保留题设未给独立性时的信息不足结论。
+ 纠正「MLE 是无偏估计」的旧答案，说明 MLE 与 MAP 均不天然无偏，并用 Gaussian 方差 MLE 给出反例。
+ Gaussian 卷积、均匀输入经 LTI 系统已标注同时属于 SS；Bayes、MLE/MAP、NP 准则已标注同时属于 PS，待处理信号课程时补齐对向题。
+ 结构计数验证通过：17 个问题均具有且仅具有一组折叠 Callout、分析、解答、拓展和关联；所有 `test/` 来源链接均存在。
