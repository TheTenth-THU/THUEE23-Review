# 课程题库整理工作底稿

本目录持久化记录面经来源核对、课程归属与题库迁移决策，配合以下已生成资料重复使用：

+ `tmp/source_text/`：面经及压缩包内可读对象的文本抽取。
+ `tmp/question_catalog.json`、`tmp/question_catalog.md`：旧题库题目目录。
+ `tmp/question_source_audit.tsv`、`tmp/question_source_review.md`：题目与来源文本的相似度审计。

课程按仓库文件夹顺序处理：电路 → 计算 → 数学 → 物理 → 信号 → 综合。每门课完成后记录来源修正、跨课程归属、未纳入项目与验证结果。

最终全目录覆盖审计发现计算分类下的 AR、DB、VI 在首轮顺序中遗漏，因此以 21—23 号补充记录；三者的实际补录仍按 AR → DB → VI 的文件夹顺序完成。编号保留真实处理过程，避免把事后补录伪装成首轮结果。
