# OS - 操作系统

## 来源核对

+ 旧题库中的用户态/内核态、临界区与 mutex/semaphore、死锁、文件描述符、非法内存访问仅能在 yj ZIP 的备考材料中找到，不能作为实际面经原题。
+ 旧「为什么需要虚拟内存」错误并列多份 2019/2020 面经；实际可由 2012 九字班面经中的「虚拟内存的概念、管理方式、TLB」支撑。
+ 2017 陈誉博明确出现修改栈空间和按键后的计算机处理过程；2020 潘美竹、荆峥明确出现进程与线程以及进程冲突。
+ 2018 与 2020 闫雯荻明确出现中断处理；2012 与 2020 闫雯荻明确出现轮询、中断和 DMA；2023 李响明确出现操作系统实现多程序运行和单处理器并发。
