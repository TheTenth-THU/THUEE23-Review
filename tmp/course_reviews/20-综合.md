# 综合面试

## 来源核对

+ 2009—2025 面经实际记录自我介绍、英语问答、个人经历、研究方法、教育、科研伦理、技术产业和国际议题；个人问题不使用备考答案扩写成现场原题。
+ 原题库把论文抄袭、SRT 成果质量和创业学业平衡并入一题，也把中非合作与俄乌战争并入一题，但它们需要完全不同的事实和答案链，本次分别拆开。
+ 个人介绍、科研贡献、优缺点和兴趣类题目没有唯一事实答案；参考解答只提供可据实填充的完整结构，不虚构考生履历。

## 迁移计划

+ 按个人介绍与经历、科研方法与诚信、技术产业与社会、校园教育与国际讨论组织。
+ 开放题均给出问题界定、主要机制、反方或风险、可执行方案和评价指标，不再使用可套用于任意题目的模板句充当分析。
+ 「关联」只指向确有直接关系的正式课程笔记；没有课程笔记的综合能力题如实标注。

## 迁移结果

+ 由 23 题重构为 26 题，全部来源前置、去除引号和可信度等级，并使用默认折叠 Callout。
+ 拆分科研诚信／SRT／创业和中非合作／俄乌战争，补充导师分歧的诚信边界、仿真的 verification／validation、技术政策的风险分层等具体内容。
+ 结构、来源路径和 Wikilink 统一验证通过。
