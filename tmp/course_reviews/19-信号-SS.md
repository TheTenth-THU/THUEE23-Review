# SS - 信号与系统

## 来源核对

+ 旧题库共 23 题，但 2024 yj 压缩包的多个出处实际指向「问题answer」「问题answer2」和「核心课复习」等备考材料。本次只把同包 `推研面经2024.md` 中实际出现的正交基、矩形脉冲、时移和微分性质保留为原题。
+ 2021 涂晨昕面经实际支持 LTI、因果、BIBO 和 Fourier 自变换；2017 陈誉博与 2024 zcy 面经实际支持卷积、冲激响应及升余弦实现，因此用真实来源恢复了被错误出处覆盖的主题。
+ 逐份补读 2009—2025 来源后，补回旧题库遗漏的 LTI 逆系统、复指数特征函数、时变系统冲激响应、功率谱、均匀随机输入、$3/4$ 重采样和匹配滤波应用等现场问题。

## 迁移计划

+ 按 LTI 表征、传输与可实现性、变换、采样和数字滤波、频谱现象、随机信号与应用重新分类。
+ 将 DSP、通信、统计信号处理和概率论共有题同步到对应课程，并在每条原题后标注多课程归属。
+ 不把不同答案链的问题强行合并；将旧题库的「零填充与带通采样」拆为独立题目，并把卷积定义、时变系统与 Gaussian／矩形卷积分层组织。

## 迁移结果

+ 重写为 28 题，全部使用默认折叠 Callout，具体回答适用条件、公式、反例、工程意义和正式笔记关联。
+ 修正 Nyquist 等号边界、终值定理极点条件、最小相位与线性相位、带通采样区间、零填充与上采样插零、匹配滤波最优性等易错点。
+ 补齐 DS 的 $3/4$ 重采样、插零和升余弦题，补齐 PR 的卷积极限与功率谱题，并在 CN 中增加升余弦的多课程标注。
+ 结构、全部来源路径和正式笔记标题统一验证通过。
+ 处理 VI 时把手抖图像模糊题建立双向多课程标注，原有题号与答案结构不变。
