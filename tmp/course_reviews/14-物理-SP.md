# SP - 固体物理基础

## 来源核对

+ 2012 分类面经实际记录晶体、准晶体、非晶体与缺陷辨识，能带理论假设、直接/间接带隙和 Bloch 定理；个人面经记录 Si 感光与发光问题。
+ 2013 面经实际记录 Si 晶体结构、掺杂与 Fermi 能级、迁移率单位、双原子链声学/光学支、掺杂意义、固体比热、金刚石的 Bravais 点阵和基元、PN/Schottky 问题。
+ 2014 面经实际记录 NaCl 结构、Si 声学/光学支数量、声子与晶格振动的宏观性质、XRD 与倒空间、MOS 与 PN 结比较及 MOS 导电机理。
+ 2017–2019 面经补充四价及 III–V 材料掺杂、空穴与迁移率、Fermi 能级位置、Si 结构、带隙温度效应及 Schottky/欧姆接触。
+ 2020–2025 面经补充倒格子与 Brillouin 区、Fermi 能级和化学势、输运与弛豫时间、有效质量、格波与 Debye 理论、能带形成、Hall/XRD 表征、半导体光电性质和 PN 结单向导通。
+ 旧题库把 2024 yj 压缩包中的备考答案误当原题，导致晶格/基元/晶胞、Bragg 定律和 PN/Schottky 比较等伪原题，也给 Si、NaCl 等题附加了多个无对应文本的来源；本次只采用压缩包内 `推研面经2024` 正文。

## 迁移计划

+ 按晶体结构与倒空间、晶格振动与热学、能带与准粒子、Fermi 统计与输运、掺杂与结器件重写。
+ 电子/光子/声子与 Fermi 能级同时属于 QS；MOS 与 PN 结同时属于 EC，完成后补齐双向标注。
+ 将「单原子链色散」恢复为 2025 原题实际问到的格波、长波声学支和声学/光学支，不保留由旧答案擅自扩写的完整推导题。

## 迁移结果

+ 重写为 24 题，按晶体结构与实验表征、晶格振动与热学、能带与准粒子、Fermi 统计与载流子、半导体结与场效应器件组织。
+ 删除仅来自 2024 yj 备考答案的伪原题；保留压缩包内实际面经提出的 Si/GaAs、光电探测与晶体结构问题。
+ 对支数与正常模数、Bloch 晶体动量与机械动量、Fermi 能级与化学势、带隙温度依赖、迁移率与 Hall 测量等易错处补齐适用条件。
+ 电子/光子/声子和 Fermi 能级两题已同步纳入 QS；PN、Schottky 和 MOS 题已与 EC 双向标注。
+ 结构与链接验证通过：24 个问题均具有且仅具有一组折叠 Callout、分析、解答、拓展和关联，来源文件及正式笔记标题均可解析。
