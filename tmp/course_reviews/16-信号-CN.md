# CN - 通信与网络

## 来源核对

+ 旧题库分散在「QUESTIONS - 信源信道与传输基础.md」「QUESTIONS - 调制与接收.md」「QUESTIONS - 网络与多址.md」三个文件中，主 `QUESTIONS.md` 只是索引。
+ 2024 yj 压缩包实际面经的信号组只记录正交基、矩形脉冲 Fourier 变换及微分性质；ASK／FSK／PSK／QAM 总比较、信源编码压缩下限和部分 Shannon 追问来自备考答案，不是现场原题。
+ 调制性能比较可由 2012、2021 实际面经恢复；Gauss 信道容量可由 2017–2024 多份实际面经恢复，因而删除错误出处而不删除真实主题。
+ 2020 面经实际问网络传输、交换机和路由器是否出现差错；旧题库把它扩写成「依据什么转发」。本次按真实问题重建网络差错与转发机制。
+ 2024 吴凌沨面经实际问多址方式与空分实现；2024 lym 面经实际问接收机带通滤波器作用，两题应拆开而非放进同一答案。

## 迁移计划

+ 合并三个伴随题库为唯一的 `QUESTIONS.md`，按信源数字化、调制编码、信道接收、网络传输、同步定位、多址可靠接收分类。
+ 删除备考答案伪原题，保留实际来源能够支持的题意；把割裂问题拆成连续编号。
+ 主动降噪同时归入 DS，重复传输与合并同时归入 PS，完成后在对应课程补题并闭合双向标注。

## 迁移结果

+ 重写为 27 题；每题均采用默认折叠的「分析与解答」Callout，并完整给出分析、解答、拓展和正式笔记关联。处理 PS 时补入匹配滤波题，完成 CN、PS、SS 三门课程的多对多记录。
+ 删除三个旧伴随题库，并同步从 `README.md` 的 Longform `ignoredFiles` 中移除旧文件名。
+ 修正升余弦频谱效率的带宽口径、Shannon 容量点的误码率解释、LNA 对输入信噪比的边界、重复合并 3 dB 增益与资源代价等易错点。
+ 当前结构、正式笔记链接与来源路径校验通过；指向 DS、PS 的跨课程题库现均已创建，SS 将在按目录顺序重写时同步标注。
