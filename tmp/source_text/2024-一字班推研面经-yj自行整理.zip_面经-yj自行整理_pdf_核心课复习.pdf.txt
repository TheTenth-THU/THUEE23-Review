记忆是在头脑中积累和保存个体经验的心理过程，记忆是人脑对外界输入的信息进行编码、存储和提取的过程
记忆是一个结构性的信息加工系统，包括三个子系统：感觉记忆，短时记忆，长时记忆
记忆包括编码、存储和提取三个基本过程
信息编码：对外界信息进行形式转换
存储：把信息编码的结果以一定形式保持在大脑中
提取：从记忆中查找已有信息的过程，包括再认和回忆
感觉记忆特点：存储时间非常短；记忆容量较大；记忆过程是无意识的自动化的，人无法控制

LLM 是指：利用海量数据进行训练，学习语言的结构、规则和语义，从而可以生成具有自然语言风格的文本或回答自然语言的
问题
语言模型旨在对于人类语言的内在规律进行建模
LLM 构建基于 transformer 架构，构建过程包括：大规模预训练、指令微调与人类对齐
LLM 适应性微调，涉及两个主要步骤：指令微调、对齐微调
指令微调数据集： • 自然语言处理任务数据集 • 日常对话数据集 • 合成数据集
人类对齐数据集： • 对齐目标一般聚焦于三个方面 – 有用性 – 诚实性 – 无害性
预训练数据主要分为两种类型：
通用文本数据：网页、书籍和对话文本等
专用文本数据：多语数据、科学文本、代码等
Transformer 的计算和存储复杂度随输入序列长度的平方级别增长
常用的预训练任务：
语言建模（ Language Modeling, LM ）： “ 预测下一个词元 ”
去噪自编码（ Denoising Autoencoding,DAE ）
混合去噪器（ Mixture-of-Denoisers, MoD ）
指令微调（ Instruction Tuning ）是指使用自然语言形式的数据对预训练后的大语言模型进行参数微调
指令微调的作用：   整体任务性能的改进     任务求解能力增强     领域专业化适配
贪心搜索问题：  在每个生成步骤中均选择最高概率的词元，这可能会由于忽略在某些步骤中概率不是最高、但是整体生成概率
更高的句子而造成局部最优
改进：束搜索、长度惩罚、重复惩罚
提示通常为包含特定任务信息的一组人工设计的输入或者可学习的特征向量，用于引导模型从输入文本或图像中提取特定任务
所需要的信息
提示学习：通过选择或生成合适的提示，引导模型适应多样化的输入和下游任务
提示的质量在很大程度上会影响 LLM 在特定任务中的表现
针对 LLM 的提示设计需要考虑四个要素：任务描述，输入数据，上下文信息，提示策略
多模态大语言模型指能够处理和整合多种模态信息（比如文本、图像和音频）的大语言模型，通过同时利用多种数据来源，实
现了模型的优化和预测能力的提升
LLM 协助自然语言处理：
LLM 在 NLP 三大经典任务：序列标注、关系抽取以及文本生成中具有较好的效果
LLM 通过上下文学习或基于特殊提示的方式解决序列标注任务
LLM 利用其出色的推理能力，借助特定提示方法完成关系抽取任务
LLM 强大的交互能力，能够与用户形成交互，提升文本生成质量
