## 知识主线

电子电路与系统基础研究如何用集总元件、半导体器件和反馈网络实现信号传输、放大、滤波、逻辑与振荡。全课程可以沿两条相互衔接的主线复习。

```text
电路模型 → 分析方法 → 动态响应 → 正弦稳态 → 频率响应 → 二端口
                                                     ↓
pn 结与二极管 → BJT／MOSFET 放大 → 运放与反馈 → CMOS 逻辑 → 振荡器
```

## 重点结构

### 线性电路

+ [[电路模型与基本定律]]：集总条件、参考方向、元件关系、功率与能量。
+ [[电路分析方法]]：节点法、网孔法、叠加、等效变换和端口定理。
+ [[动态电路]]：电容、电感、互感、一阶与二阶暂态。
+ [[正弦稳态分析]]：相量、阻抗、谐振和复功率。
+ [[频率响应与滤波]]：传递函数、极零点、Bode 图和滤波器指标。
+ [[二端口网络]]：用参数矩阵封装复杂网络并完成互连。

### 器件与系统

+ [[二极管电路]]：pn 结模型、整流、限幅、钳位和稳压。
+ [[BJT 放大电路]]：工作区、偏置、小信号模型和基本放大级。
+ [[MOSFET 与放大电路]]：阈值、工作区、跨导、共源级和电流镜。
+ [[运算放大器与反馈]]：虚短虚断、基本运算、反馈增益与稳定性。
+ [[CMOS 数字电路]]：反相器 VTC、噪声容限、门电路、传输门和存储单元。
+ [[振荡器与信号发生]]：起振条件、线性振荡器和松弛振荡器。

> [!tip]
> 对任何电路先判断模型和工作区，再列 KCL／KVL；若含储能元件，区分暂态与稳态；若含有源器件，先求直流工作点，再建立小信号或开关模型。
