## 知识主线

电子电路与系统基础回答三个递进问题：如何把真实电磁结构抽象成可求解的电路，如何预测电路随时间与频率变化的响应，以及如何利用非线性器件和反馈实现放大、滤波、逻辑与振荡。全课程的共同方法是「**确定模型与工作区 → 选择状态量或端口变量 → 写约束与元件关系 → 求解并回代检查 → 解释功率、带宽、稳定性和非理想边界**」。

```text
真实电磁系统
    ↓ 集总近似、参考方向、元件模型
电路建模与分析 ──→ 动态与交流网络 ──→ 端口与频率响应
                                      ↓
                                半导体非线性器件
                                  ↙          ↘
                    模拟功能电路              CMOS 数字电路
                放大／反馈／振荡          逻辑／时序／存储
```

## 章节结构

### [[电路建模与分析]]

从真实系统的集总近似出发，把拓扑约束与元件本构关系组合成方程，再利用等效定理把复杂网络压缩为端口模型。

+ [[电路模型与基本定律]]：参考方向、功率与能量、KCL／KVL、独立源与受控源、线性化和模型边界。
+ [[电路分析方法]]：节点法、网孔法、叠加、电源变换、Thévenin／Norton 等效及最大功率传输。

### [[动态与交流网络]]

把储能元件引入的初始状态，与正弦稳态、$s$ 域、零极点和端口参数统一起来；时域暂态和频域选择性是同一系统动力学的不同观察方式。

+ [[动态电路]]：电容、电感、互感、状态连续性、一阶与二阶响应、能量耗散和开关瞬间。
+ [[正弦稳态分析]]：相量、阻抗、复功率、谐振、品质因数与变压器阻抗反射。
+ [[频率响应与滤波]]：传递函数、极零点、Bode 图、滤波逼近、群时延及时频折中。
+ [[二端口网络]]：$Z$、$Y$、$h$、传输参数，互易与对称，端接、互连和级联。

### [[半导体器件]]

从非线性伏安关系出发，先确定直流工作区，再在工作点附近线性化；同一器件在大信号分析中表现为整流器或开关，在小信号分析中表现为跨导放大器。

+ [[二极管电路]]：pn 结、分段模型、小信号与结电容、整流、限幅、钳位和稳压。
+ [[BJT 放大电路]]：结偏置、工作区、偏置稳定、小信号模型、三种基本组态和电流镜。
+ [[MOSFET 与放大电路]]：沟道形成、工作区、体效应与沟道长度调制、基本放大级和 MOS 电流镜。

### [[模拟功能电路]]

把器件级增益封装为功能模块，并通过负反馈设定精确增益、输入输出电阻和带宽；正反馈与选频网络则把直流能量转化为周期信号。

+ [[运算放大器与反馈]]：理想运放条件、基本运算、反馈拓扑、环路增益、稳定性和非理想限制。
+ [[振荡器与信号发生]]：起振、稳幅、LC／RC／环形／松弛振荡器，以及频率稳定性和相位噪声。

### [[CMOS 数字电路]]

由 MOSFET 开关模型建立互补逻辑，沿「反相器 VTC → 组合门 → 传输门 → 锁存器与触发器 → SRAM」理解逻辑恢复、延迟、功耗和状态保存。

## 复习指引

先用 [[QUESTIONS|推免面试回忆题]] 诊断薄弱环节，再沿对应父章节回到知识链。口述任何电路题时，建议依次完成：

1. 声明集总、线性、小信号、正弦稳态或理想器件等模型条件。
2. 标出参考方向、工作区、初始状态或反馈极性。
3. 选择节点、网孔、状态、相量或二端口变量，写出最少的一组独立方程。
4. 回代检查工作区、量纲、极限情形、功率方向和稳定性。
5. 补充至少一个由寄生参数、带宽、噪声、器件容差、压摆率或传播延迟造成的非理想限制。

> [!tip]
> 「直流工作点＋小信号模型」与「初始状态＋自然响应」是两套最容易混淆的分解。前者在线性化非线性器件，后者在分解动态系统的响应；两者都必须先保留决定模型的静态量，再分析叠加在其上的变化量。
