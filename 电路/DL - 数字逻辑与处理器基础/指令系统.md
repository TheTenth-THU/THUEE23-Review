## 指令集设计

### 目标

指令集中需要包含的信息：
- 指令的操作
- 操作数、数据或地址
	- 访问寄存器数据的地址
	- 立即数

同时，还需预留以后加入新指令需要的空间。

### 约束

+ **最小访存单位**：由对齐要求，单条指令长度是字节（Byte）的整数倍。
+ **支持一定量的寄存器**
+ **区分不同的指令**

### 设计一例

例如，设置单条指令长度为 32 bit，简化指令共 29 条，则：
- 至少用 5 bit **操作码** 区分不同指令
- 考虑预留空间，则可用 6 bit 保存操作码，用 26 bit 保存操作数或地址。
假定一共 32 个寄存器，则需要 5 bit 保存寄存器编号。

#### 算术、逻辑指令

##### 无立即数的算术、逻辑指令

```
add a0, a1, a2						# a0 = a1 + a2
sub a0, a1, a2						# a0 = a1 - a2
and a0, a1, a2						# a0 = a1 & a2
or  a0, a1, a2						# a0 = a1 | a2
xor a0, a1, a2						# a0 = a1 ^ a2
sll a0, a1, a2						# a0 = a1 << a2
srl a0, a1, a2						# a0 = a1 >> a2
sra a0, a1, a2						# a0 = a1 >> a2
```

编码方案：
```tx
| `操作码` | `目的寄存器` | `源寄存器1` | `源寄存器2` | `预留`   |
|:------:|:----------:|:---------:|:---------:|:------:|
| 6 bit  | 5 bit      | 5 bit     | 5 bit     | 11 bit |
```

##### 有立即数的算术、逻辑指令

```
addi a0, a1, 10						# a0 = a1 + 10
subi a0, a1, 10						# a0 = a1 - 10
andi a0, a1, 10						# a0 = a1 & 10
ori  a0, a1, 10						# a0 = a1 | 10
xori a0, a1, 10						# a0 = a1 ^ 10
slli a0, a1, 10						# a0 = a1 << 10
srli a0, a1, 10						# a0 = a1 >> 10
srai a0, a1, 10						# a0 = a1 >> 10
```

编码方案：
```tx
| `操作码` | `目的寄存器` | `源寄存器` | `补码存储的立即数` |
|:------:|:----------:|:--------:|:---------------:|
| 6 bit  | 5 bit      | 5 bit    | 16 bit          |
```

#### 分支指令

##### 无立即数的分支指令

```
beq a0, a1, label					# if a0 == a1 then goto label
blt a0, a1, label					# if a0 < a1 then goto label
bgt a0, a1, label					# if a0 > a1 then goto label
```

编码方案：
```tx
| `操作码` | `源寄存器1` | `源寄存器2` | `地址` |
|:------:|:---------:|:---------:|:----:|
| 6 bit  | 5 bit     | 5 bit     | 16 bit |
```

其中，`地址` 仅有 16 bit，而一般地址均为 32 bit，因此需要进行扩展。
+ 一条指令4个字节（32 bit），且内存中地址按字节编号，那么每条指令的低 2 位都是 `00`。
+ 目标地址往往接近当前地址，因此可以使用 `当前地址` + `偏移地址` 的方式计算目标地址。
	```
	PC_target = PC_current + {Offset[15:0], 2'b00}
	```

##### 有立即数的分支指令

```
beqi a0, 10, label					# if a0 == 10 then goto label
blti a0, 10, label					# if a0 < 10 then goto label
bgti a0, 10, label					# if a0 > 10 then goto label
```

编码方案：
```tx
| `操作码` | `源寄存器` | `补码存储的立即数` | `地址` |
|:------:|:--------:|:---------------:|:----:|
| 6 bit  | 5 bit    | $m$ bit          | $(21-m)$ bit |
```

`地址` 可表示的范围更加有限。

#### 访存指令

```
lw a0, addr							# a0 = Memory[addr]
sw a0, addr							# Memory[addr] = a0
```

编码方案：
```tx
| `操作码` | `目的寄存器` | `地址` |
|:------:|:----------:|:----:|
| 6 bit  | 5 bit      | 21 bit |
```

内存 `地址` 为 21 bit，可表示的范围有限。可以类似上面的[[#分支指令]]，使用 `当前地址` + `偏移地址` 的方式计算目标地址；也可以使用寄存器存储地址，这里的 `地址` 只需为寄存器编号。

#### 跳转与过程调用指令

```
j    label							# goto label
ret  a0								# return to a0
call a0, label						# call label and give return to a0
```

编码既可以是类似[[#访存指令]]结构的方式，用 5 bit 保存一个寄存器：
```tx
| `操作码` | `寄存器` | `地址` 或 `预留` |
|:------:|:------:|:----:|
| 6 bit | 5 bit | 21 bit |
```
也可以使用一个固定的预定义寄存器，26 bit 保存地址：
```tx
| `操作码` | `地址` |
|:------:|:----:|
| 6 bit | 26 bit |
```

> [!example]+ MIPS 指令集架构
> [[MIPS 指令集架构]]是一个典型的精简指令集（RISC）架构，其**指令长度**固定为 **32 bit**，有 **32 个**长度为 32 bit 的寄存器。
