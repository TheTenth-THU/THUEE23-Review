## 知识主线

本课程从「如何用有限数字电路完成可编程计算」出发，依次建立表示、组合逻辑、时序状态、指令系统、微体系结构与存储系统。前半部分回答一个功能怎样变成同步数字电路，后半部分回答一组指令怎样变成可运行的处理器。

## 重点结构

+ [[数制与布尔代数]]给出位串的数值解释、补码运算和逻辑函数化简方法。
+ [[组合逻辑]]把布尔函数实现为译码器、多路选择器、加法器和 ALU 等无状态电路。
+ [[时序逻辑]]引入锁存器、触发器、寄存器、计数器和有限状态机，并建立同步时序约束。
+ [[指令系统]]定义软件可见的操作、操作数与编码，[[MIPS 指令集架构]]给出一套典型 RISC 实例。
+ [[微处理器]]把指令的取指、译码、执行、访存和写回组织为单周期或多周期数据通路。
+ [[流水线]]让多条指令重叠执行，并分别处理 [[结构冒险]]、[[数据冒险]] 与 [[控制冒险]]。
+ [[存储器与总线]]讨论 SRAM、DRAM、Cache、存储层次以及处理器与外设之间的数据交换。
