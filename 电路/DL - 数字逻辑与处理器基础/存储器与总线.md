## 存储系统的基本指标

存储器以地址选择数据项，核心指标包括容量、访问延时、吞吐率、单位 bit 成本、功耗和非易失性。寄存器最快但昂贵，外部存储容量大但延时高，因此处理器采用分层结构折中。

## 半导体存储器

### SRAM

**静态随机存取存储器 (static random-access memory, SRAM)** 的典型单元用交叉耦合反相器保存状态，并通过访问晶体管连接差分位线。只要供电存在，状态无需刷新。

SRAM 速度快、读写控制简单，但单元面积大，主要用于寄存器堆和片上 Cache。

### DRAM

**动态随机存取存储器 (dynamic random-access memory, DRAM)** 用电容上的电荷表示 bit。单元密度高，但读操作具有破坏性，且漏电要求周期刷新。

DRAM 常把地址分为行、列两次送入，行地址选通后整行进入感应放大器，再由列地址选择数据。行命中与换行访问具有明显不同的延时。

### ROM 与非易失存储

ROM、Flash 等在断电后仍保存内容。ROM 适合固定控制表，Flash 适合固件和大容量存储，但写入粒度、擦除次数与延时不同于 SRAM／DRAM。

```tx
| 类型 | 存储机制 | 是否刷新 | 典型位置 | 主要取舍 |
|:---|:---|:---:|:---|:---|
| 寄存器 | 触发器 | 否 | CPU 数据通路 | 最快、面积最大 |
| SRAM | 双稳态单元 | 否 | 片上 Cache | 快、密度较低 |
| DRAM | 电容电荷 | 是 | 主存 | 密度高、延时较大 |
| Flash | 浮栅电荷 | 否 | 固件与外存 | 非易失、写擦较慢 |
```

## 存储层次与局部性

**时间局部性**是指近期访问的数据很可能再次访问；**空间局部性**是指相邻地址很可能很快被访问。存储层次以固定大小的**块 (block)** 在相邻层之间搬移数据，从而让小而快的上层捕获大部分访问。

> [!definition] 平均访存时间
> 对一级 Cache，平均访存时间为
> $$
> \mathrm{AMAT}=t_{\mathrm{hit}}+r_{\mathrm{miss}}P_{\mathrm{miss}}
> $$
> 其中 $t_{\mathrm{hit}}$ 为命中时间，$r_{\mathrm{miss}}$ 为缺失率，$P_{\mathrm{miss}}$ 为一次缺失的额外代价。

## Cache

### 地址划分与映射

Cache 将地址划分为标记、组索引和块内偏移：

$$
\text{address}=\underbrace{\text{tag}}_{\text{标记}}\mid\underbrace{\text{index}}_{\text{组索引}}\mid\underbrace{\text{offset}}_{\text{块内偏移}}
$$

若块大小为 $B=2^b$ byte，则偏移占 $b$ bit；若共有 $S=2^s$ 组，则索引占 $s$ bit，其余高位为 tag。

+ **直接映射 (direct mapped)** 每组一行，命中判断快，但冲突多。
+ **全相联 (fully associative)** 任意块可进入任意行，冲突少但需并行比较所有 tag。
+ **$E$ 路组相联 ($E$-way set associative)** 每组有 $E$ 行，在命中时间与冲突率之间折中。

### 替换与写策略

组内没有空行时需选择替换对象，常用 LRU、近似 LRU、FIFO 或随机策略。

+ **写直达 (write-through)** 同时更新 Cache 与下层存储，状态简单但写流量大，通常配合写缓冲。
+ **写回 (write-back)** 只更新 Cache，并用 dirty bit 标记；被替换时才写入下层，流量小但控制更复杂。
+ **写分配 (write-allocate)** 写缺失时先把块调入 Cache；**非写分配**则直接写下层而不调入。

### 3C 缺失

Cache 缺失可分为：

+ **强制性缺失 (compulsory miss)**：某块第一次被访问。
+ **容量缺失 (capacity miss)**：工作集超过 Cache 总容量，即使全相联也会发生。
+ **冲突缺失 (conflict miss)**：受映射限制，多个活跃块竞争同一组。

> [!note] 优化方向并不独立
> 增大块可利用空间局部性，却会增加缺失代价并减少可容纳块数；提高相联度可减少冲突，却会增加命中比较延时。应以 AMAT 而非单独的命中率评价设计。

## 总线与外设

**总线 (bus)** 是多个模块共享的通信通道，通常包含地址线、数据线和控制线。地址指出访问对象，数据线承载内容，控制线描述读写方向、有效性、响应和中断等事务状态。

### 同步与异步总线

+ **同步总线**由公共时钟规定各阶段，控制简单、吞吐率高，但长度和设备速度受时钟约束。
+ **异步总线**用请求／应答握手推进事务，可连接速度差异大的设备，但每次传输需要额外握手延时。

多个主设备共享总线时必须**仲裁 (arbitration)**。集中式仲裁由统一仲裁器授权，分布式仲裁则由设备共同决定优先级。

### I/O 访问

+ **程序查询**由处理器反复读取设备状态，简单但浪费处理时间。
+ **中断驱动 I/O**让设备就绪后请求处理器服务，适合低到中等速率事件。
+ **直接存储器访问 (DMA)** 由 DMA 控制器在设备和内存之间批量搬移数据，处理器只负责建立传输并处理完成事件。

> [!danger] 总线冲突
> 多个推挽输出不能直接并联驱动同一总线。共享数据线必须通过三态门、多路选择器或规定的开漏／开集电极结构，确保任一时刻只有合法驱动关系。

存储系统决定指令和数据能否及时到达 [[微处理器]]；Cache 的延时与缺失又会直接改变 [[流水线]] 的停顿行为。
