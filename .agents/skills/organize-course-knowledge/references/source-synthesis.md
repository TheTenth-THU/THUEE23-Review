# 来源提取与综合

## 建立临时来源视图

先在工作记忆中记录来源名称、资料类型、覆盖主题、可信用途和已知缺口。不要把该清单提交为课程正文，除非用户明确要求保留来源索引。

按用途理解不同资料：

+ 教学大纲或复习范围用于判断覆盖边界，不单独作为知识正确性的依据。
+ 教材和正式讲义用于定义、条件、推导和标准符号。
+ 课堂课件用于教学顺序、强调重点、图示和例题，但可能省略论证。
+ 习题、试题和辅导材料用于识别典型方法、易错点与综合应用，不要反向把应试题型当成知识体系。
+ 既有 Markdown 用于保留已经稳定的表述、链接和符号，但仍需与原始资料核对。

## 选择读取深度

+ **结构审计或重构规划**：盘点全部来源文件名与主题覆盖，读取 Index、全部章节标题和少量代表正文；只抽查能影响重大结构判断的原始资料。
+ **局部补全或增量更新**：只精读受影响知识单元及其直接依赖，检查父章节和 Index 是否需要同步回修。
+ **完整新建或覆盖核验**：先对全部来源做覆盖轮，再按拟议章节分批精读；不要在知识地图尚未形成时逐页深挖单一来源。
+ 来源数量很大时，先按主题、时间和资料类型分组，再选择代表文件。把未精读范围列入交付限制，不要用无边界阅读替代任务判断。

## 分轮提取

1. **覆盖轮**：快速浏览所有来源，列出主题与缺口，暂不逐句改写。
2. **结构轮**：提取核心概念及其依赖、推导和应用关系，形成知识地图。
3. **证据轮**：围绕拟写章节精读相关页，记录定义条件、关键步骤、图形和例题用途。
4. **写作轮**：综合多个来源重新组织表述，不按单一来源顺序拼接。
5. **核对轮**：从成稿反查来源，确认没有改变适用条件、符号含义和结论范围。

## 提取知识单元

按需记录以下信息：

+ 名称、别名和首次依赖。
+ 解决的问题或描述的现象。
+ 直观图景与正式定义。
+ 假设、定义域、边界条件和适用范围。
+ 核心关系式、推导链或运行机制。
+ 结果的数学、物理或工程含义。
+ 与相邻概念的区别、等价关系或转化条件。
+ 典型方法、最小示例、反例和常见误区。

没有必要让每个知识单元包含全部字段。删除只重复标题、不能支持理解或复习的材料。

## 处理冲突与缺失

+ 优先判断差异是否来自符号、约定、近似层级或适用条件，而非直接判定某一来源错误。
+ 能由权威来源或推导消解时，采用一致表述，并在正文中解释必要的约定。
+ 无法消解时，不要静默选择；在交付说明中列出冲突和影响。
+ 图片、页码或局部定义缺失时保留明确占位说明，不要凭上下文臆造内容。
+ 从 PDF 提取复杂公式、表格或图形时渲染原页进行视觉核对。

## 控制信息密度

+ 核心层保留定义、关键结论、主推导、典型方法和概念关系。
+ 支撑层保留有助于理解核心层的例子、证明思路和限制条件。
+ 扩展层只保留对课程复习确有价值的历史、旁支推导或高级应用，必要时使用可折叠 Callout。
+ 不要用删去解释换取简短，也不要用完整搬运来源换取表面上的全面。
