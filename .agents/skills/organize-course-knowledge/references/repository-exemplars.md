# 仓库样例

样例用于观察组织方法，不代表当前文件完全符合项目规范。读取任务相关的少量文件，并以仓库现状重新验证，不要复制整章或固化旧错误。

## 固体物理基础

优先观察：

+ `物理/SP - 固体物理基础/Index.md`：父子场景与知识链式导航。
+ `物理/SP - 固体物理基础/固体能带理论.md`：从周期势、Bloch 定理和近似模型逐步建立能带图景。
+ `物理/SP - 固体物理基础/固体的结构与结合.md`：父章节以概要和链接组织子章节。

借鉴模型假设、推导和物理解释之间的衔接。不要照搬其标题语言或链接；当前 Index 曾出现畸形 Wikilink，使用前重新审计。

## 操作系统

优先观察：

+ `计算/OS - 操作系统/Index.md`：按五大管理功能建立课程主线。
+ `计算/OS - 操作系统/处理机管理.md`：父章节概括进程、线程、通信和调度之间的关系。
+ `计算/OS - 操作系统/进程.md`：从并发执行的问题引出抽象，再展开状态和控制机制。

借鉴「问题—抽象—机制—权衡」结构、对比表格和失败场景。使用前检查附件和当前项目格式，不要把既有文件视为免检模板。

## 电磁场与波

优先观察：

+ `物理/EM - 电磁场与波/Electrostatics.md`：父章节概览与详细子章节的链接关系。
+ `物理/EM - 电磁场与波/Maxwell's Equations.md`：方程、作用力和能量关系的整合。
+ `物理/EM - 电磁场与波/Electric Displacement.md`：从极化到辅助场、边界条件和应用的推进。

借鉴跨章节链接和物理量之间的关系说明。不要以其 Index 为格式范本；当前 Index 含课程和考试信息，与项目现行规则不一致。

## 待调整课程中的反模式

检查《高等微积分》时重点观察：

+ 单个文件是否承载多个独立复习单元并达到数百至上千行。
+ 定义、定理和证明是否连续堆入 Callout，缺少比较、动机和方法选择。
+ Index 是否链接到准确标题，章节之间是否完全孤立。

代表文件包括 `数学/AC - 高等微积分/导数与微分.md`、`多元函数微分学.md` 和 `Index.md`。

检查《线性代数》时重点观察：

+ `scenes` 是否为空或与现有文件不一致。
+ 导航是否指向不存在的章节。
+ 内容是否呈现为高密度定义、定理和例题汇编，缺少概念主线。
+ 线性映射、子空间、秩、正交性和分解之间的依赖是否被文件边界割裂。

代表文件包括 `数学/LA - 线性代数/Index.md` 和 `矩阵及其运算.md`。
